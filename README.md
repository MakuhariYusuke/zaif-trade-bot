# Zaif Trade Bot

A reinforcement learning-based trading bot for cryptocurrency markets.

## Project Structure

This project has been organized into the following directories:

### `ztb/` - Main Python Package
- `analysis/` - Analysis and diagnostic scripts
- `cache/` - Data caching utilities
- `config/` - Configuration management
- `data/` - Data processing and loading utilities
- `evaluation/` - Backtesting and evaluation tools
- `features/` - Feature engineering components
- `inference/` - Model inference and prediction
- `metrics/` - Performance metrics and evaluation
- `ops/` - Operational utilities
- `preprocessing/` - Data preprocessing pipelines
- `risk/` - Risk management components
- `scripts/` - Utility scripts
- `tests/` - Test suites
- `trading/` - Trading environment and live trading
- `training/` - Model training algorithms and trainers
- `types/` - Type definitions and protocols
- `utils/` - General utility functions

### `docs/` - Documentation
- `planning/` - Project planning documents
- `bugs/` - Bug reports and fixes
- `reports/` - Analysis reports and results

### `config/` - Configuration Files
- Training configurations
- Environment settings
- Model parameters

### `data/` - Data Files
- `datasets/` - Training and testing datasets
- `results/` - Experiment results and outputs
- `cache/` - Cached data and computations
- `logs/` - Application logs
- `temp/` - Temporary files

### `tests/` - Test Suites
- `unit/` - Unit tests
- `integration/` - Integration tests
- `training/` - Training-related tests

## Setup

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run tests: `npm run test:unit`

## Development

- Use virtual environments (automatically ignored by .gitignore)
- Run tests before committing
- Follow the organized directory structure for new code

## Git LFS

Large binary files (models, datasets) are tracked using Git LFS. Make sure Git LFS is installed and initialized.
