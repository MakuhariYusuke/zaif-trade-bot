## 📊 品質改善概要

### v437での改善点

- **品質フィルタリング**: NaN率>10%、分散=0、ゼロ率>80%の特徴量を自動除去
- **牛/熊市場バランス**: 市場レジーム別特徴量のバランス改善
- **相関制御**: 過度な相関を持つ特徴量の品質管理

### クリティカルな除去特徴量
以下の特徴量はv437で**完全に除去**されています：

#### 1. dividends
- **除去理由**: 常にゼロ値 (分散 = 0.00e+00, ゼロ率 = 100.00%)
- **影響**: 学習に悪影響を及ぼす定数特徴量

#### 2. stock_splits
- **除去理由**: 常にゼロ値 (分散 = 0.00e+00, ゼロ率 = 100.00%)
- **影響**: 学習に悪影響を及ぼす定数特徴量

### 品質フィルタリング基準
v437では以下の品質基準を適用：

```yaml
quality_thresholds:
  max_nan_rate: 0.10      # NaN率 > 10% の特徴量を除去
  min_variance: 1.0e-8    # 分散 < 1e-8 の特徴量を除去
  max_zero_rate: 0.80     # ゼロ率 > 80% の特徴量を除去
  max_outlier_rate: 0.30  # 外れ値率 > 30% の特徴量を除去
  max_correlation: 0.95   # 相関係数 > 95% の特徴量を注意
```
