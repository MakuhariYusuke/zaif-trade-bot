# 08. HOLD張り付き現象（Hold Freeze）の分析と対策

## 1. 現象の概要
v457の20,000ステップ訓練において、エージェントが**100% Short（全期間売り張り付き）**の状態に陥り、学習が停滞する現象が発生した。
市場が下落トレンドであったため、Shortを持ち続けることが局所的最適解となり、そこからの脱却（利確・ドテン）が行われなかった。

ユーザーからの報告により、これは過去のバージョン（v450, v455等）でも発生していた「Hold Freeze」と呼ばれる既知の問題であることが判明した。

## 2. 原因分析（Code Archaeology）

### 現状の実装（v457 / v456後期）
`ztb/trading/rewards/fast_intraday.py` の `compute_hft_reward` 関数を確認したところ、以下のような「簡易版」実装となっていた。

```python
# Simple reward: PnL - Costs
# Normalize by max_position for scale consistency
reward = (pnl - total_cost) / max(max_position, eps)
```

関数シグネチャには `hold_ramp`, `edge_penalty_rate`, `vol_floor` などのパラメータが存在するが、**関数内部では一切使用されていない**。
これは、v456開発後期において「複雑なペナルティがエージェントのポジション保有を阻害し、利益が出ない」という問題に対処するために、ペナルティを全削除した経緯（v456 Retrospective参照）によるものである。

### 過去の教訓（v455 / v456）
- **v455**: `Time-Decay Penalty`（時間経過による減点）や`Low-Vol Penalty`を導入し、Hold Freezeを解消したが、パラメータが厳しすぎて「Short-Termすぎて手数料負けする」副作用もあった。
- **v456**: 上記の反動でペナルティを削除した結果、「100% Buy（またはSell）」の単純な戦略（Buy & Hold）に退行した。

### 結論
現在の「ペナルティなし」の状態では、トレンドがある方向に出ている場合、エージェントにとって「ポジションを持ち続け、決済コスト（Fee + Slippage）を支払わない」ことが最も安全で報酬が高い行動となってしまっている。

## 3. 解決策：v455型ペナルティの復活と調整

v455で成果を上げたペナルティロジックを復活させる。ただし、v455のように厳しすぎて「保有恐怖症」にならないよう、マイルドな設定から導入する。

### 復活させるロジック
1.  **Time-Decay Penalty (時間減衰)**
    - 一定時間（`hold_grace`）を超えた保有に対して、ステップごとにペナルティ（`hold_ramp`）を課す。
    - これにより「永遠に持ち続ける」ことの期待値をマイナスにし、決済を促す。

2.  **Edge Penalty (エッジ不足ペナルティ)**
    - 期待される利益（ATR変動幅）がコスト（手数料）を下回る場合のエントリーを抑制。
    - 無駄な微細トレードを防ぐ。

### 提案パラメータ（v457用）

| パラメータ | v455設定 | v457推奨 | 意図 |
| :--- | :--- | :--- | :--- |
| `hold_grace` | 10 steps | **20-50 steps** | スイングトレードを許容するため、猶予時間を長くする。 |
| `hold_ramp` | 0.01 | **0.001 - 0.005** | v455の1/10〜1/2程度。急激なペナルティによるパニック売りを防ぐ。 |
| `edge_penalty_rate` | 1.0 | **0.1 - 0.5** | エントリー阻害を弱める。 |

## 4. 具体的な改修計画

1.  **`ztb/trading/rewards/fast_intraday.py` の修正**
    - コメントアウトされている（または削除されている）ペナルティ計算ロジックを復元する。
    - 引数として渡されたパラメータが実際に計算に使われるようにする。

2.  **設定ファイル（`config/v457/base/config.yaml` 相当）の調整**
    - `reward_params` セクションに推奨パラメータを設定する。

## 5. 期待される効果
- 長時間（例: 50ステップ以上）のHoldに対して徐々にコストが発生するため、トレンドが弱まった時点で「一度利確する」インセンティブが生まれる。
- これにより、100% Holdの一本調子な挙動から、適度な回転（Swing）を行う挙動へと変化することが期待される。
