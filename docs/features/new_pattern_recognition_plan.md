# 新規パターン認識実装計画

## 概要

Action Signal Guideに以下の新しいパターン認識機能を追加します：

1. **グランビルの法則 (Granville's Law)**
2. **ダウ理論 (Dow Theory)**
3. **平均足 (Heikin-Ashi)**

## 1. グランビルの法則 (Granville's Law)

### 理論的背景
ジョセフ・グランビルによる取引ルール。価格と出来高の関係に基づく8つの基本ルール。

### 主要ルール
1. **買いシグナル**: 価格が上昇し、出来高が増加
2. **売りシグナル**: 価格が下降し、出来高が増加
3. **買いシグナル**: 価格が上昇し、出来高が減少（弱気相場でのみ有効）
4. **売りシグナル**: 価格が下降し、出来高が減少（強気相場でのみ有効）
5. **買いシグナル**: 価格が横ばい、出来高が増加
6. **売りシグナル**: 価格が横ばい、出来高が減少
7. **買いシグナル**: 価格が下降し、出来高が減少（弱気相場でのみ有効）
8. **売りシグナル**: 価格が上昇し、出来高が減少（強気相場でのみ有効）

### 実装計画
- **ファイル**: `granville_law.py`
- **クラス**: `GranvilleLawRecognizer`
- **入力**: OHLCVデータ
- **出力**: SignalResult (買い/売り/中立)
- **パラメータ**:
  - 出来高変化率の閾値
  - 価格変化率の閾値
  - 市場トレンドの判定期間

### 考慮点
- 様々な解釈が存在するため、複数の実装バリエーションを検討
- 市場トレンド（強気/弱気）の判定が必要
- 出来高データの品質が重要

## 2. ダウ理論 (Dow Theory)

### 理論的背景
チャールズ・ダウによる市場分析の基礎理論。6つの基本原則に基づく。

### 主要原則
1. **平均は全てを織り込む**: 市場は全ての情報を反映
2. **市場には3つのトレンドがある**: 主要トレンド、二次トレンド、短期トレンド
3. **主要トレンドは3段階で進む**: 蓄積、参加、分配
4. **平均は相互に確認しなければならない**: インデックス平均と輸送平均
5. **出来高はトレンドを確認する**: 出来高がトレンドを支持
6. **トレンドは明確なシグナルが出るまで継続**: 明確な転換シグナルが必要

### 実装計画
- **ファイル**: `dow_theory.py`
- **クラス**: `DowTheoryRecognizer`
- **入力**: 複数インデックスの価格データ
- **出力**: SignalResult (トレンド確認/転換シグナル)
- **パラメータ**:
  - トレンド判定期間
  - 確認のための閾値
  - 複数平均の相関閾値

### 考慮点
- 複数インデックスのデータが必要
- 長期的なトレンド分析に適する
- シグナル発生が稀だが信頼性が高い

## 3. 平均足 (Heikin-Ashi)

### 理論的背景
日本の伝統的なローソク足の変種。価格変動を滑らかにし、トレンドを明確に表示。

### 計算式
```
HA_Close = (Open + High + Low + Close) / 4
HA_Open = (前回のHA_Open + 前回のHA_Close) / 2
HA_High = max(High, HA_Open, HA_Close)
HA_Low = min(Low, HA_Open, HA_Close)
```

### 実装計画
- **ファイル**: `heikin_ashi.py`
- **クラス**: `HeikinAshiRecognizer`
- **入力**: OHLCデータ
- **出力**: SignalResult (トレンド方向/強度)
- **パラメータ**:
  - 計算期間
  - トレンド判定の閾値
  - シグナル強度の計算方法

### 考慮点
- 既存のローソク足パターン認識と統合可能
- ノイズを減らしトレンドを明確化
- リアルタイム分析に適する
