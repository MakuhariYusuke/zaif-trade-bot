```
┌──────────────────────────────────────────────────────────────┐
│                    Signal Quality Scorer                      │
│                                                              │
│  ┌────────────┐  ┌────────────┐  ┌────────────┐            │
│  │    RSI     │  │   MACD     │  │    BB      │            │
│  │ 過売り検出 │  │トレンド強度│  │偏差分析    │            │
│  │ (25%)     │  │ (25%)      │  │ (15%)      │            │
│  └────────────┘  └────────────┘  └────────────┘            │
│                                                              │
│  ┌────────────┐  ┌────────────┐  ┌────────────┐            │
│  │    ATR     │  │  Volume    │  │ Momentum   │            │
│  │ボラティリティ│ │比率        │  │価格変化率  │            │
│  │ (10%)      │  │ (10%)      │  │ (15%)      │            │
│  └────────────┘  └────────────┘  └────────────┘            │
│                         │                                    │
│                         ↓                                    │
│              加重平均スコア計算 (0-100)                      │
│                         │                                    │
│                         ↓                                    │
│              指標の一致度 → 信頼度 (0-1)                    │
│                         │                                    │
│                         ↓                                    │
│     ┌──────────────────────────────────────────┐            │
│     │  実行判定: Score ≥ 60 AND Confidence ≥ 70│            │
│     └──────────────────────────────────────────┘            │
│                                                              │
└──────────────────────────────────────────────────────────────┘

例: 買いシグナルの場合

RSI < 30 (過売り)         → 100点
MACD histogram > 0        → 80点
BB position < 0.3         → 70点
ATR > 平均               → 60点
Volume ratio > 1         → 80点
Momentum > 0             → 50点

加重平均 = 100×0.25 + 80×0.25 + 70×0.15 + 60×0.10 + 80×0.10 + 50×0.15
         = 25 + 20 + 10.5 + 6 + 8 + 7.5
         = 77点 ← スコア

指標標準偏差 = 11.5
信頼度 = 1 - (11.5/50) = 0.77 ← 信頼度高い

→ 実行判定: 77 ≥ 60 AND 0.77 ≥ 0.70 ✓ 実行
```
