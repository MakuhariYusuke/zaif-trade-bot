# SAC v435 開発計画

## 概要
v435は、v430の取引パフォーマンス問題を解決し、v434.2の制御アルゴリズム改善を統合した次世代取引システムです。

## 目標
- v430の16%ロングポジション勝率問題を解決
- v430の過度な取引頻度を抑制
- v434.2の制御アルゴリズム改善を取引環境に適用
- 安定した収益性を実現

## 主要コンポーネント

### 1. 強化された報酬関数
- ロング/ショートポジションの非対称性考慮
- 取引頻度ペナルティの最適化
- リスク調整リターンの重視

### 2. 適応型特徴量選択
- 相関分析による特徴量削減
- 市場状況に応じた特徴量重み付け
- マルチタイムフレーム特徴量統合

### 3. 高度なリスク管理
- 動的ポジションサイジング
- ドローダウン制御
- 相場変動適応

### 4. 改善されたBayesian最適化 ✅
- GP-based samplerによる高精度最適化
- 堅牢な評価関数（リトライ＆キャッシュ）
- 適応型動的ウェイト更新
- ドメイン知識に基づくパラメータ空間設計
