# ========================================
# 💡 推奨パラメータ調整
# ========================================

## A. 緊急対応（Critic Loss の安定化）

### 1. Learning Rate を下げる
**現在**: 0.0003
**推奨**: 0.0001 (67%減) または 0.00005 (83%減)
**理由**: Critic Lossの爆発を防ぐ。小さいステップで安定的に学習。

### 2. Batch Size を増やす
**現在**: 64
**推奨**: 128 または 256
**理由**: より多くのサンプルで勾配を安定化。分散を減らす。

### 3. Gamma (割引率) を下げる
**現在**: 0.99
**推奨**: 0.95 または 0.98
**理由**: 将来の報酬への依存度を下げ、Q値の爆発を防ぐ。

### 4. Gradient Clipping を追加
**現在**: なし
**推奨**: max_grad_norm = 0.5 または 1.0
**理由**: 勾配の大きさを制限し、学習を安定化。

## B. エントロピー調整（探索の最適化）

### 5. Target Entropy を明示的に設定
**現在**: "auto" (おそらく -1.0 for continuous action space dim=1)
**推奨**: -0.5 または -0.3
**理由**: 
  - 連続行動空間の次元が1なので、target_entropy = -dim(A) = -1.0
  - これだと探索が強すぎる可能性
  - より小さい絶対値（-0.5など）で適度な探索を維持

### 6. Learning Starts を増やす
**現在**: 100
**推奨**: 500 または 1000
**理由**: 十分なランダムサンプルを集めてから学習開始。初期の不安定性を回避。

## C. バッファとサンプリング

### 7. Buffer Size の調整
**現在**: 10000
**推奨**: 
  - 短期訓練（<10k）: 10000 (現状維持)
  - 中長期（10k-50k）: 20000
  - 長期（100k）: 50000
**理由**: より多様な経験から学習。ただし、メモリ使用量とのバランス。

### 8. Train Frequency
**現在**: 1 (毎ステップ)
**推奨**: 4 または 8
**理由**: 
  - 計算効率の向上
  - より多くのデータ収集後に学習（安定性向上）

### 9. Gradient Steps
**現在**: 1
**推奨**: 4 (train_freq=4と合わせて)
**理由**: データ収集とネットワーク更新のバランス

## D. ネットワーク構造（次のステップで検討）

### 10. Policy と Value Network のサイズ調整
**検討事項**:
  - より小さいネットワーク（過学習防止）
  - Layer Normalization の追加
  - より浅いネットワーク
