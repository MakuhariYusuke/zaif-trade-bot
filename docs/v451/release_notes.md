# v451 "Chronos" Release Notes

## 概要
v451 (コードネーム: Chronos) は、以前のモデル (Iter 12) で確認された「時間的盲点」と「レジーム認識不足」を解消するために設計されたメジャーアップデートです。
市場の微細構造 (Market Microstructure) を明示的に特徴量として取り込むことで、特定の時間帯やボラティリティ環境下でのパフォーマンス低下を防ぎます。

## 主な変更点

### 1. 循環的時間特徴量 (Cyclical Time Features)
従来の「0-23」の整数表現ではなく、時間を円環構造として学習させるための三角関数特徴量を導入しました。
- `hour_sin`, `hour_cos`: 24時間周期の表現 (例: 23時と0時の連続性を保持)
- `minute_sin`, `minute_cos`: 60分周期の表現
- `day_of_week_sin`, `day_of_week_cos`: 週間サイクルの表現

**目的:** 14:00, 17:00, 01:00 などの特定の市場イベント時間帯における学習効率の向上。

### 2. ボラティリティ・レジーム認識 (Volatility Regime Awareness)
市場の状態を動的に分類し、エージェントに現在の「相場環境」を伝えます。
- `volatility_rank`: 直近のボラティリティが過去の分布の中でどの位置にあるか (0.0 - 1.0)
- `regime_trend`: トレンド状態 (RANGING / TRENDING)
- `regime_volatility`: 変動状態 (LOW / HIGH / EXTREME)

**目的:** "Medium-Low" ボラティリティ環境下での無駄なトレードの抑制と、急変動時の対応力向上。

### 3. データパイプラインの刷新
- `sac_v451_feature_engineering.py`: 新しい特徴量生成ロジックの実装。
- 事前計算済みデータセット (`data/btc_jpy_1m_v451.csv`) の使用により、学習時の計算コストを削減。

## 学習結果 (Phase 7 Initial Run)

- **総ステップ数:** 20,000
- **アクション分布:**
    - HOLD: 31.5%
    - BUY: 31.2%
    - SELL: 37.3%
    - **評価:** 非常にバランスの取れたアクション分布を達成。以前のモデルで見られた「BUYのみ」「HOLDのみ」への退化は見られない。
- **レジーム別挙動:**
    - コンソリデーション (保ち合い) 局面においても、BUY/SELL/HOLD をバランスよく使い分けており、過剰な取引や完全な沈黙に陥っていない。

## 今後の展望
- **長時間学習:** 現在の20,000ステップは初期検証用です。100k~1Mステップの学習を行うことで、より洗練された戦略を獲得できる可能性があります。
- **ハイパーパラメータチューニング:** 新しい特徴量セットに合わせたネットワーク構造の最適化。

## 結論
v451 は、実取引に向けた「根本的な修正」の第一歩として、エージェントに「時間」と「環境」の文脈を与えました。初期学習の結果は、エージェントがこれらの情報を活用して多様な行動を選択していることを示唆しています。
