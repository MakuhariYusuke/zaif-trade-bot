# SAC v434.2 開発計画ドキュメント

## 概要
SAC v434.1のバックテスト分析結果に基づき、根本的な問題（0%収益、過度な取引頻度、決定論的行動）を解決するためのv434.2開発計画。

## SAC v434.1 分析結果

### 主要問題点
- **収益性**: 0%収益（期待値ゼロ）
- **取引頻度**: 92.4%のアクションが取引（過度な取引）
- **行動パターン**: 完全に決定論的（多様性不足）
- **特徴量利用**: 特徴量の活用不足

### 根本原因
1. **報酬関数設計の欠陥**: 取引コストが低すぎ、利益ボーナスが不十分
2. **特徴量相関の未考慮**: 多重共線性による学習の不安定化
3. **環境設定の不備**: 現実的でない取引条件

## v434.2 改善計画

### 1. 報酬関数改良
#### 取引コスト強化
- **v434.1**: 取引コスト 0.001 (0.1%)
- **v434.2**: 取引コスト 0.015 (1.5%) - **10倍強化**
- **目的**: 過度な取引を抑制

#### 利益ボーナス増加
- **ATR係数**: 1.5 → 5.0 (**3.3倍**)
- **ポートフォリオ係数**: 3.0 → 10.0 (**3.3倍**)
- **目的**: 明確な利益シグナル提供

#### 損失ペナルティ強化
- **損失ペナルティ**: -0.2 → -1.0 (**5倍**)
- **目的**: 損失回避行動の強化

#### 新規ペナルティ追加
- **アクション頻度ペナルティ**: 0.05
- **取引間隔ボーナス**: 0.03（最小間隔5ステップ）
- **利益実現ボーナス**: 2.0（最小利益100円）
- **目的**: 取引頻度制御と利益確定促進

### 2. 特徴量システム拡張
#### 相関分析統合
- **ピアソン相関分析**: 線形関係検出
- **スピアマン相関分析**: 非線形関係検出
- **相互情報量**: 非線形依存関係分析
- **階層的クラスタリング**: 特徴量類似性分析

#### ニュース特徴量統合
- **TextSentimentEncoder活用**: BERTベース感情分析
- **金融特化感情分析**: ドメイン特化辞書ベース
- **時間集約特徴量**: ニュースの時間窓集約
- **価格影響分析**: ニュースが価格に与える影響

#### 特徴量重要度分析
- **リターンとの相関**: 各特徴量の予測力評価
- **多重共線性削減**: 相関の高い特徴量の除去
- **適応的特徴量選択**: 市場状態に応じた特徴量重み付け

### 3. 取引コスト柔軟対応
#### 多取引所対応
- **Zaif**: 0.1% (基準)
- **BitFlyer**: メイカー-0.02%、テイカー0.12%
- **Coincheck**: **無料**（当座運用）
- **Binance**: 0.1%
- **Bybit**: メイカー-0.025%、テイカー0.075%

#### 戦略別取引所推奨
- **高頻度取引**: コストが低い取引所優先
- **スイング取引**: 安定性重視
- **スケルピング**: 超低コスト取引所

### 4. 環境設定最適化
#### 最大ポジションサイズ
- **v434.1**: 制限なし
- **v434.2**: **100%**（当座の間、最低取引単位考慮）

#### 学習環境改善
- **相関削減**: 有効化（閾値0.85）
- **ランダムスタート**: 有効化（決定論回避）
- **連続行動空間**: SAC用最適化
