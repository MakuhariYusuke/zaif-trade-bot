# v453 Threshold Relaxation (2025-12-14)

## 1. 背景
v451時代に導入された「閾値10倍化（Multiplier 10.0）」という強力な取引抑制ロジックは、現在のモデル（v453）にとっては過剰な制約となっていることが判明した。
特に、`HIGH_VOLATILITY` や逆張り（トレンド相場での反対売買）において、10倍の閾値は実質的に取引を禁止するに等しく、モデルが持つスキャルピング能力やリスクヘッジ能力を殺してしまっている可能性がある。

## 2. 変更内容
`ThresholdManager` のハードコードされた倍率を緩和した。

| 条件 | 変更前 (v451 Legacy) | 変更後 (v453 Relaxed) | 理由 |
| :--- | :--- | :--- | :--- |
| **High Volatility** | **10.0x** | **1.5x** (当初3.0xから再緩和) | ノイズは避けたいが、チャンスまで潰さないように緩和。 |
| **Bull Trend (Sell)** | **10.0x** | **1.5x** (当初3.0xから再緩和) | 強い上昇中でも、短期的な調整（押し目）での利益機会を残す。 |
| **Bear Trend (Buy)** | **10.0x** | **1.5x** (当初3.0xから再緩和) | 強い下落中でも、短期的な反発（リバウンド）での利益機会を残す。 |
| **Consolidation** | 1.0x (Fixed) | 1.0x (Unchanged) | Baselineの利益を維持するため変更なし。 |

## 3. 検証結果 (2025-12-15)

### 実験1: Multiplier 3.0x
- **Total Return**: -38.45%
- **結果**: 失敗。損失が拡大。

### 実験2: Multiplier 1.5x
- **Total Return**: -38.45% (3.0xと完全に同一)
- **結果**: 失敗。

### 考察
- **Buggy (v3 behavior)**: Multiplier **1.0x** (実質) -> **+12%**
- **Strict (v451 Fix)**: Multiplier **10.0x** -> **+6%**
- **Relaxed (1.5x ~ 3.0x)**: Multiplier **1.5x ~ 3.0x** -> **-38%**

この結果は、**「中途半端な緩和（1.5x ~ 3.0x）」が最も危険である**ことを示唆している。
- **1.0x (Buggy)**: 全ての微細なスキャルピング（Action > 0.01）を許可。利益が損失を上回る。
- **10.0x (Strict)**: 強い確信（Action > 0.1）のみ許可。取引回数は激減するが、大怪我もしない。
- **1.5x ~ 3.0x**: 「損失を生むノイズ（0.015 < Action < 0.1）」を通してしまい、かつ「利益を生む微細スキャルピング（0.01 < Action < 0.015）」をブロックしてしまっている可能性が高い。

**結論**:
モデルの収益源は **Action値 0.01 ~ 0.015 の範囲にある微細なトレード** に集中している可能性が高い。
したがって、**Multiplierを 1.0x (またはそれ以下) に戻す** ことが、v3のパフォーマンスを再現する唯一の道であると考えられる。
