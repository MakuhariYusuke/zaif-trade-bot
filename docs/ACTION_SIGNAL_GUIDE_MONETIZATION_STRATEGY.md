### 統合ドキュメントの主要内容

#### システム概要
Action Signal GuideはSAC（Soft Actor-Critic）強化学習システムの補助機能として位置づけられる高度なパターン認識システムです。

**主要特徴**:
- 27種類以上のテクニカル分析パターン認識
- 適応型アルゴリズムと動的特徴量調整
- 多時間足分析と信号集約
- 並列処理による高速化

#### 実装状況
- **完了**: 基本パターン認識、適応型アルゴリズム、多時間足分析
- **進行中**: 動的閾値調整、リスク管理機能、パフォーマンス分析
- **計画**: 機械学習ベース集約、オンライン学習、リアルタイム適応

#### パフォーマンス指標
- **シグナル生成**: 5,000データポイントで5,000シグナル生成
- **パターン別性能**: ADX(0.54), Wave(0.63), Oscillator(0.72)
- **相関分析**: 利益相関最大0.106（ADXパターン）

#### 使用方法
```python
from ztb.trading.strategies.action_signal_guide import ActionSignalGuide

# 設定取得
config = get_optimized_config()

# 初期化
guide = ActionSignalGuide(config)

# シグナル生成
signals = guide.generate_signals(market_data)
```
