## 🎯 追加された主要コンテンツ

### improvement値に基づく判断基準 (全ドキュメント共通)

| improvement | 信頼度 | Phase 2 範囲 | コマンド例 |
|-------------|--------|-------------|-----------|
| **≥10** | 🟢 高 | 最適値のみ | `--search_range 32` |
| **5-10** | 🟡 中 | 最適値±1段階 | `--search_range 16,32,64` |
| **<5** | 🔴 低 | より広範囲 | `--search_range 8,16,32,64,128` |

### 結果ファイル確認方法 (全ドキュメント共通)

```powershell
# Windows - notepad
notepad binary_search_results\batch_size_history.json

# Windows - PowerShell整形
Get-Content binary_search_results\batch_size_history.json | ConvertFrom-Json | ConvertTo-Json -Depth 10

# Linux/Mac - jq
cat binary_search_results/batch_size_history.json | jq .
```

### JSON結果の見方 (全ドキュメント共通)

```json
{
  "iteration_3": {
    "candidate_value": 32,        // ← Phase 1で選ばれた最適値
    "score": -185.5,
    "baseline_score": -194.2,
    "improvement": 8.7            // ← この値で判断!
  }
}
```
