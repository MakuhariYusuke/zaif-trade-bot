# パラメータ検証追跡シート

## 📋 概要
このドキュメントは、バイナリサーチ最適化における**未検証パラメータ**と**再検証が必要なパラメータ**の進捗を追跡します。

**最終更新**: 2025年10月10日
**管理責任**: 継続的な最適化プロセスの一環として更新

---

## 🎯 検証ステータス定義

| ステータス | 説明 | 次アクション |
|----------|------|------------|
| ✅ **完了** | 50k以上で統計的に有意な結果を取得済み | 本番適用可能 |
| ⚠️ **要再検証** | 差分が小さく信頼区間内、追加検証必要 | 100k or マルチシード |
| ❌ **未検証** | 短期探索のみ、長期検証未実施 | 50k~100k検証実施 |
| 🔄 **検証中** | 現在トレーニング実行中 | 完了待ち |
| ⏸️ **保留** | 優先度低、他パラメータ確定後に実施 | 待機 |

### 優先度 High: 未検証パラメータ (影響大) - ⚠️ 下記は旧情報、上記完了分を参照

| # | パラメータ | 現在値 (短期) | ステータス | 優先度 | 推奨検証構成 | 期待効果 | 担当者 | 期限 |
|---|-----------|-------------|-----------|--------|-------------|---------|--------|------|
| 1 | `batch_size` | 16 | ❌ 未検証 | 🔴 High | 20k粗選別 → 50k精査 | サンプル効率向上、KL挙動改善 | - | - |
| 2 | `learning_rate` | 1e-5 | ❌ 未検証 | 🔴 High | 10k粗選別 → 50k精査 | 旧結果(0.0094)との整合性確認 | - | - |
| 3 | `max_grad_norm` | 0.5 | ❌ 未検証 | 🔴 High | 30k × 2シード | 勾配安定性、分散削減 | - | - |

**詳細**:

#### 1. batch_size
- **現状**: 短期2048ステップで16/64/256全て同一スコア(-346.51)
- **仮説**: 小さいバッチサイズで高速化とKL制御が改善する可能性
- **検証手順**:
  1. Phase 1 (20k): 範囲16-256で粗選別、候補3つに絞る
  2. **Phase 1→Phase 2 判断基準**:
     - `binary_search_results/batch_size_history.json` の最終iterationでimprovement値を確認
     - improvement ≥10 → 高信頼度: 最適値のみPhase 2へ
     - improvement 5-10 → 中信頼度: 最適値±1段階をPhase 2へ
     - improvement <5 → 低信頼度: より広い範囲でPhase 2を実施
  3. Phase 2 (50k): Phase 1結果に基づく範囲で精査、差分≥5を検出
- **成功基準**: 差分≥5 (95%CI=±7.1に対し有意傾向)
- **リスク**: KL早期停止頻発の可能性、モニタリング必須
- **💡 詳細**: `PARAMETER_VALIDATION_QUICK_REFERENCE.md` の「Phase 1→Phase 2 移行ガイド」参照

#### 2. learning_rate
- **現状**: 短期で1e-5が選択されたが、旧最適化(10k)では0.009375625
- **仮説**: 短期では差が出ず、長期で学習速度の違いが顕在化
- **検証手順**:
  1. Phase 1 (10k): 1e-5, 1e-4, 1e-3, 0.0094の4候補スクリーニング
  2. Phase 2 (50k): 上位2候補で精査
- **成功基準**: 差分≥10で明確な優劣
- **リスク**: 高い学習率で不安定化の可能性、clip_range調整も検討

#### 3. max_grad_norm
- **現状**: デフォルト0.5のまま、バイナリサーチ未実施
- **仮説**: 勾配クリッピングで報酬分散が削減される
- **検証手順**:
  1. Phase 1 (30k × seed1): 範囲0.1-2.0で探索
  2. Phase 2 (30k × seed2): ベスト値で再現性確認
- **成功基準**: 2シード平均で差分≥5、報酬分散σ削減≥10%
- **リスク**: 差分が小さい可能性、シード差で判定

**詳細**:

#### 4. gamma (割引率)
- **現状**: 50kで0.8475が最適、差分1~2
- **問題**: 95%CI=±7.1に対し差分が小さく、統計的有意性不明
- **検証手順**:
  - Option A: 100k×1走で信頼区間を半減 (±5程度)
  - Option B: 50k×2シード平均でSE改善 (√2で±5程度)
- **成功基準**: 差分≥3が信頼区間外に出る
- **リスク**: 100k実行コスト高、Option B推奨

#### 5. n_epochs (エポック数)
- **現状**: 50kで16が最適、差分<1
- **問題**: ノイズレベルで優劣不明
- **検証手順**: gammaと同様、100k or 50k×2シード
- **成功基準**: 差分≥2で判定可能
- **リスク**: 効果が微小な場合、16をデフォルト継続も選択肢

#### 6-9. gae_lambda, clip_range, target_kl, ent_coef
- **共通現状**: 短期2048で全て横並び(-346.51)
- **仮説**: 長期で勾配更新の質に影響が出る
- **検証手順**: 各パラメータ50k×1走 (計200k)
- **成功基準**: いずれか1つで差分≥5
- **リスク**: 4つとも差が出ない可能性、その場合デフォルト継続

## 💡 Tips

### 🔧 実行前の環境確認 (重要!)

**1. 仮想環境のアクティベート**

検証スクリプトを実行する前に、必ず仮想環境をアクティベートしてください:

**Windows (PowerShell)**:
```powershell
.\.venv\Scripts\Activate.ps1
# 成功するとプロンプトに (.venv) が表示される
```

**Windows (Command Prompt)**:
```cmd
.venv\Scripts\activate.bat
```

**Linux/Mac**:
```bash
source .venv/bin/activate
```

**2. 環境確認コマンド**

```bash
# Python実行環境の確認
python -c "import sys; print(sys.executable)"
# 出力例: C:\Users\Admin\dev\zaif-trade-bot\.venv\Scripts\python.exe

# 必須パッケージの確認
python -c "import numpy, pandas, stable_baselines3, gymnasium; print('All packages OK')"
```

**3. トラブルシューティング**

| エラー | 原因 | 解決策 |
|--------|------|--------|
| `ModuleNotFoundError: No module named 'numpy'` | 仮想環境未アクティベート | 上記コマンドで仮想環境をアクティベート |
| `ImportError: DLL load failed` | PyTorch/CUDA問題 | `pip install torch --index-url https://download.pytorch.org/whl/cpu` |
| パッケージ不足 | 依存関係未インストール | `pip install -r requirements.txt` |

### 並列実行でスピードアップ
```bash
# 異なるパラメータを別々のGPU/マシンで同時実行
# GPU 0: batch_size探索
CUDA_VISIBLE_DEVICES=0 python -m ztb.training.binary_search.batch_size_optimized --timesteps 50000 &

# GPU 1: learning_rate探索
CUDA_VISIBLE_DEVICES=1 python -m ztb.training.binary_search.learning_rate_optimized --timesteps 50000 &
```

### リソース管理
- **1つのパラメータ50k検証**: 約5-8時間 (環境依存)
- **推奨**: 夜間実行でスケジューリング
- **モニタリング**: TensorBoardでリアルタイム監視

### 早期停止判定
- KL早期停止が多発 → target_kl調整検討
- 報酬が発散 → learning_rate, clip_range再調整
- スコア横並び継続 → timesteps不足、100k拡張
