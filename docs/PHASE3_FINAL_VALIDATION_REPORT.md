## 使用例

### 基本的なハイパーパラメータ最適化
```python
from ztb.training.unified_optimizer import UnifiedOptimizer, OptimizationConfig

config = OptimizationConfig(max_trials=50)
optimizer = UnifiedOptimizer(config)
optimizer.initialize_hyperparameter_optimizer("bayesian")

def objective(params):
    return -(params["x"] - 2)**2 - (params["y"] - 3)**2

search_space = {
    "x": {"type": "float", "low": 0, "high": 5},
    "y": {"type": "float", "low": 0, "high": 5}
}

result = optimizer.optimize_hyperparameters(objective, search_space)
print(f"Best params: {result.best_params}, Score: {result.best_score}")
```

### 自動最適化パイプライン
```python
pipeline_result = optimizer.run_automatic_pipeline(
    base_params={"learning_rate": 0.001, "batch_size": 32},
    objective_function=objective,
    search_space=search_space,
    multi_timeframe_functions={"1m": tf_objective_1m, "5m": tf_objective_5m}
)

if pipeline_result["final_recommendation"]["action"] == "deploy":
    print("Deploying optimized parameters!")
```
