## ✅ P0 修正（ロギング スロットル）の効果検証

### 修正内容の確認

**File**: `scripts/v456/train_v456_optimized.py`

```python
# 修正前:
last_save_step = 0  # ← ロギングと保存で共用 ❌

# 修正後:
self.last_log_step = 0    # ロギング用
self.last_save_step = 0   # 保存用

def _on_step(self) -> bool:
    # ロギング: 200 ステップ毎
    if self.num_timesteps - self.last_log_step >= 200:
        self._log_milestone()
        self.last_log_step = self.num_timesteps
    
    # 保存: 1000 ステップ毎
    if self.num_timesteps - self.last_save_step >= 1000:
        self._save_checkpoint()
        self.last_save_step = self.num_timesteps
```
