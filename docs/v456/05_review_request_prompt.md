## 🔍 Review Request: v456 Cryptocurrency Auto-Trading System Design

### Context

私は仮想通貨（BTC/JPY）の自動取引システムを開発しています。これまでv448〜v455の複数のイテレーションを経て、v456として新たな設計を行いました。

**プロジェクトの大義**: 短期間での高収益性システム構築

**現状の課題**:
- v455: 安定性は確保したが、バックテストで-9.3%の損失
- v454: 97.5%の高勝率だが、収益0%（麻痺状態）
- v453: +2.23%の収益だが、トレード数激減
- 1分足単体では手数料（0.1%）を超えるエッジを見つけることが困難

### Documents to Review

以下の5つのドキュメントをレビューしてください：

1. **00_improvement_proposal.md** - 改善提案書（全体計画）
2. **01_technical_specification.md** - 詳細技術仕様書
3. **02_feature_engineering_spec.md** - 特徴量設計書
4. **03_implementation_checklist.md** - 実装チェックリスト
5. **04_self_review.md** - 自己レビュー（批判的分析）

### Key Design Decisions

1. **マルチタイムフレーム（MTF）特徴量**: 5m/15m/1hの上位足情報を追加
2. **統合シグナルシステム**: RL出力 + テクニカル指標の融合
3. **Soft Filter**: 危険な状況でも完全禁止ではなくポジション縮小
4. **GRU Policy Network**: 時系列の文脈を理解するRecurrent構造
5. **Calibration Gate**: 期待値（EV）に基づくエントリー判定
