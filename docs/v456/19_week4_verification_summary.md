## 技術的なポイント

### なぜ 5000ステップで十分か？

1. **エピソード数の充分性**
   - 5000ステップ = 約5,000エピソード
   - 統計学: 30〜50でも基本統計は信頼可能
   - 訓練初期は特性が顕著→少数サンプルで検出可能

2. **根因の明確性**
   - Issue 1: drawdown制限 → 物理的制約 (100%再現)
   - Issue 2: 報酬関数 → 学習結果 (傾向明確)
   - ノイズではなく、本質的な問題

3. **時間効率性**
   - テスト訓練: 1分
   - 分析: 5分
   - 本格訓練不回避の判定: 6分

### なぜ修正が必要か？

| 修正なし | 修正あり |
|---------|---------|
| 100万ステップ訓練 | 20K+20K+50K検証 |
| 12時間かかる | 1時間で終了 |
| Issue残存 | Issue解決済み |
| 学習不能 | 学習可能 |
