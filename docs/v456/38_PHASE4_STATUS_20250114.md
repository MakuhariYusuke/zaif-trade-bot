## 2. Core Components

### 2.1 WalkForwardSplitter

**Purpose**: Generate rolling time-series windows preventing look-ahead bias

```python
class TimeSeriesWindow(NamedTuple):
    window_id: int
    train_start: int
    train_end: int
    val_start: int
    val_end: int
    test_start: int
    test_end: int

class WalkForwardSplitter:
    def __init__(
        initial_train_pct: float = 0.50,
        val_pct: float = 0.15,
        test_pct: float = 0.15,
        step_pct: float = 0.15
    )
    def split(df) -> List[TimeSeriesWindow]
```

**Window Generation Example** (1000 bars):
```
Window 0: Train [0:500]   Val [500:650]   Test [650:800]
Window 1: Train [0:600]   Val [600:750]   Test [750:900]
Window 2: Train [0:700]   Val [700:850]   Test [850:1000]
```

**Key Features**:
- ✅ Time-series safe (no future data leakage)
- ✅ Expanding training (more data per window)
- ✅ Out-of-sample test always on future data
- ✅ Configurable train/val/test percentages

### 2.2 WalkForwardModelEvaluator

**Purpose**: Train SAC models per window and aggregate metrics

```python
@dataclass
class WindowPerformance:
    window_id: int
    val_roi: float                # In-sample return
    test_roi: float               # Out-of-sample return
    sharpe_ratio: float
    max_drawdown: float
    win_rate: float
    trades: int

class WalkForwardModelEvaluator:
    def train_and_evaluate_window(
        df, window, timesteps: int
    ) -> WindowPerformance
```

**Evaluation Pipeline**:
1. Data splitting (train/val/test)
2. SAC training on training period
3. Validation evaluation (in-sample)
4. Test evaluation (out-of-sample)
5. Metrics aggregation

**Metrics Computed**:
- ROI: Return on Investment (%)
- Sharpe Ratio: Risk-adjusted returns
- Max Drawdown: Worst-case decline
- Win Rate: Profitable trades (%)
- Trade Count: Total executed trades

---

### 2.3 WalkForwardResult

**Purpose**: Aggregate window results and compute consistency metrics

```python
@dataclass
class WalkForwardResult:
    windows: List[TimeSeriesWindow]
    performances: List[WindowPerformance]
    average_val_roi: float
    average_test_roi: float
    test_roi_std: float          # Over-fitting indicator
    average_sharpe: float
    sharpe_consistency: float
    average_win_rate: float
    overfitting_ratio: float     # |val_roi - test_roi| / |val_roi|
```

**Over-fitting Detection**:
- `overfitting_ratio < 0.20`: Robust model ✅
- `overfitting_ratio 0.20-0.50`: Moderate over-fitting ⚠️
- `overfitting_ratio > 0.50`: Severe over-fitting ❌

### 3.1 Import Resolution

**Challenge**: `ztb/evaluation/` modules need access to `scripts/v456/train_and_evaluate_v456_phase3`

**Solution**: Dynamic sys.path injection

```python
# In walk_forward_evaluator.py
import sys
from pathlib import Path

project_root = Path(__file__).resolve().parent.parent.parent
scripts_path = project_root / "scripts" / "v456"
if str(scripts_path) not in sys.path:
    sys.path.insert(0, str(scripts_path))
```

**Benefits**:
- ✅ ztb/evaluation remains independent
- ✅ No circular imports
- ✅ Works from any working directory

## 8. Key Metrics & Interpretations

### 8.1 ROI (Return on Investment)

```
Calculation: (final_balance - initial_balance) / initial_balance
Range: -1.0 to +∞
Interpretation:
  -0.30 = -30% loss (severe)
  0.00 = No profit/loss (breakeven)
  0.10 = +10% return (good)
  0.50 = +50% return (excellent)
```

### 8.2 Sharpe Ratio

```
Calculation: (mean_return - rf_rate) / std_return
Typical Range: 0.0 to 2.0
Interpretation:
  < 0.5 = Poor (high risk per unit return)
  0.5-1.0 = Acceptable
  1.0-2.0 = Good (balanced risk-return)
  > 2.0 = Excellent (rare)
```

### 8.3 Over-fitting Ratio

```
Calculation: |val_roi - test_roi| / |val_roi|
Range: 0.0 to ∞
Interpretation:
  0.0-0.20 = No over-fitting (✅ Robust)
  0.20-0.50 = Moderate over-fitting (⚠️ Watch)
  > 0.50 = Severe over-fitting (❌ Reject)

Example:
  val_roi = 5.23%, test_roi = 4.19%
  ratio = |0.0523 - 0.0419| / 0.0523 = 0.199 (19.9% - ROBUST!)
```
