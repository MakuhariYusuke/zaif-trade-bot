### 段階2: 報酬関数チューニング

**時間**: 15分  
**ステップ数**: 20,000  
**ファイル**: `ztb/trading/rewards/fast_intraday.py`  

**修正内容**:

現在の `compute_hft_reward()` は:
```
reward = pnl - fee - slippage
```

これを:
```
reward = (pnl - fee - slippage) × 0.01  # スケーリング
       + 0.01 × (action_diversity_bonus)  # アクション奨励
```

**実装ポイント**:
1. 報酬スケーリング: `/100` で小資金に対応
2. アクション奨励: 新規ポジション/決済で +0.01
3. マイナス値を避ける: reward = max(reward, -0.1)

**期待結果**:
- 報酬平均: -0.078 → -0.01 ～ 0.05 ✓
- アクション: HOLD 100% → Buy/Sell 各5-20% ✓

**検証方法**:
1. 20,000ステップ訓練実行
2. アクション分布 90%以上 HOLD → 改善確認
3. Issue 2 解決確認
