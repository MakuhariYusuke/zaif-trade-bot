# 現在の残課題、システム俯瞰、改善点、今後の展望

## システム俯瞰

Zaif Trade Botは、Stable-Baselines3のSAC (Soft Actor-Critic) を基盤とした強化学習ベースの取引ボットプロジェクトです。主な目的は、高収益性を実現するための自動取引システムの開発です。現在のバージョンはSAC v444で、市場レジーム適応機能を強化しています。

### 主要コンポーネント
- **環境 (Environment)**: `HeavyTradingEnv` - 取引環境のコア。観測空間 (212特徴量)、行動空間 (連続/離散)、報酬計算を管理。
- **報酬計算 (Reward Calculator)**: PnLベースの報酬にペナルティ (ポジション、アクション、ドローダウン、強制バランス) を加えた複合報酬システム。
- **正規化 (Normalization)**: `VecNormalize` と `NormalizationStats` を用いた観測データの正規化。トレーニング時の統計を保存/適用。
- **トレーニング (Training)**: SACトレーナーによる学習。レジーム適応、カリキュラム学習をサポート。
- **バックテスト (Backtest)**: 学習済みモデルの評価。行動分布のバランス、利益分析を実施。
- **Action Signal Guide**: 高度なパターン認識システム。適応型アルゴリズム、信号集約、多時間足分析を実装。
- **ユーティリティ**: 特徴量エンジニアリング、多タイムフレーム分析、ログ/デバッグツール。

### Action Signal Guide 現在の実装状況

**実装済み機能**:
- **並列処理**: ThreadPoolExecutorを使用したパターン認識の並列実行（2.2倍速度向上）
- **適応型特徴量前処理**: 市場レジームに応じた動的特徴量スケーリングと正規化
- **LRUキャッシュ**: メモリ効率の高いキャッシュシステム（サイズ制限、TTL対応）
- **信号集約**: 重み付き平均ベースの高度な信号統合アルゴリズム
- **多時間足サポート**: 階層的時間軸分析とアライメントスコアリング
- **パターン統計**: 継続的なパフォーマンス監視と適応

**パターン認識カテゴリ** (25+種類):
- 調和パターン (Harmonic Patterns)
- ダウ理論 (Dow Theory)
- フィボナッチ分析 (Fibonacci)
- キャンドルスティック (Candlestick)
- 移動平均 (Moving Averages)
- モメンタム指標 (Momentum)
- ボラティリティ分析 (Volatility)
- 出来高分析 (Volume)

**技術仕様**:
- 並列処理: 4スレッド (自動調整)
- キャッシュ: LRU 1000エントリ、TTL 300秒
- 特徴量: 動的スケーリング、異常値除去
- 信号集約: 強度×信頼度重み付け
- 多時間足: 5段階階層分析

## 現在の残課題

### 即時対応が必要な項目
1. **Git Push**: ローカルコミットをリモートリポジトリにプッシュ。コマンド: `git push origin main`。
2. **Lintingエラーの修正**: Pre-commitフックで検出されたmypy, ruffなどのエラーを修正。既存コードの型安全性を向上。
3. **バックテストの追加検証**: アクション分布の安定性を確認。長期間のバックテストを実行し、行動スティッキングの再発を監視。

### 潜在的な問題
- **アクション分布の不安定性**: 確率的予測モードで改善されたが、決定論的モードでのスティッキングリスク残存。
- **特徴量パイプラインの整合性**: トレーニングとバックテスト間の特徴量数 (212) の一致を確認したが、将来の変更で再不一致の可能性。
- **報酬計算のチューニング**: 強制バランスペナルティの効果をさらに検証。スケーリングや重みの調整が必要。
