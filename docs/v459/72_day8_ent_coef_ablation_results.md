## 重大な発見

### 仮説検証結果: **棄却**

70#/71# の仮説「ent_coef=0.01が探索不足でHOLD過多→性能劣化」は**棄却**される。

**実際の結果:**
```
ent_coef=0.01 (探索最小) → ROI最良 (-25.90%), HOLD最大 (66.7%)
ent_coef=0.05 (探索増加) → ROI最悪 (-37.79%), HOLD減少 (40.4%)
ent_coef=0.1  (探索増加) → ROI改善 (-27.65%), HOLD最小 (34.7%)
ent_coef=auto (適応的)   → ROI中間 (-27.88%), HOLD中間 (44.0%)
```

### 新仮説: **取引自体が損失源**

| 観察 | 解釈 |
|------|------|
| HOLD↑ → ROI↑ | 取引を避けるほど損失減少 |
| ent_coef=0.01が最良 | 探索不足ではなく「適切な消極性」 |
| ent_coef=0.05が最悪 | 中途半端な探索が最も有害 |
| ent_coef=0.1とautoが同等 | 高探索≠高性能 |

### 根本問題の示唆

1. **取引コスト未最適化**: 0.1%のtransaction_costが過大
2. **報酬設計の欠陥**: 取引を促進するインセンティブなし
3. **データ期間の問題**: 3ヶ月データで学習→トレンドなしの横ばい市場？
4. **特徴量の限界**: 現特徴量では予測不能

## 考察

### 1. ent_coef効果の非線形性

```
ROI = f(ent_coef)

      -25% |     *                           (0.01: 最良)
      -27% |                      *     *    (0.1, auto)
      -30% |
      -35% |
      -38% |            *                    (0.05: 最悪)
           +----+----+----+----+----+----
              0.01  0.05  0.1  auto

→ U字型ではなく、低ent_coefが一貫して優位
```

### 2. SAC_TUNED vs SAC_DEFAULT再解釈

| 設定 | ent_coef | Day 8 Phase A ROI |
|------|----------|-------------------|
| SAC_TUNED | 0.01 | -29.45% |
| SAC_DEFAULT | auto | -4.70% |

Day 8 Phase A では SAC_DEFAULT (auto) が優位だったが、今回のablationでは:
- ent_coef=0.01: -25.90%
- ent_coef=auto: -27.88%

**矛盾点**: 同じent_coef=0.01なのにPhase A (-29.45%) とPhase B (-25.90%) で差異

**原因候補**:
1. Phase Aは seed=42,123 のみ、Phase Bは4 seeds → サンプリング誤差
2. 他パラメータ影響（gamma=0.95 vs 0.99 がPhase Aでは異なる）

### 3. gamma/他パラメータの影響可能性

Phase A SAC_DEFAULT:
- gamma=0.99, batch=256, gradient_steps=1, ent_coef=auto

Phase B (全条件):
- gamma=0.95, batch=128, gradient_steps=2

**Phase A vs Phase B の差はent_coef以外のパラメータ差異による可能性**

## 結論

### 主要結論

1. **ent_coef=0.01は探索不足ではない** - むしろ現環境で最適
2. **取引を増やすほど損失増加** - 根本的な問題は報酬/環境設計
3. **ent_coefはSAC_TUNED劣化の主因ではない** - 他パラメータ（gamma等）の検証が必要

### Day 8総括

| Phase | 発見 | SAC_TUNED害因への貢献度 |
|-------|------|------------------------|
| A | scale=100統一でも-24.75%の純SAC効果 | 交絡排除で効果確認 |
| B | ent_coef単独では説明不能 | 0% (ent_coef=0.01が最良) |

### 次ステップ推奨

1. **gamma ablation**: 0.95 vs 0.99 の比較（優先度1）
2. **batch_size ablation**: 128 vs 256 の比較（優先度2）
3. **gradient_steps ablation**: 1 vs 2 の比較（優先度3）
4. **報酬設計見直し**: 取引促進インセンティブの追加検討
