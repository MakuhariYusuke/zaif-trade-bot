## 2. 詳細分析

### 2.1 45# Day5との差分分析

| 項目 | 45# Day5 | 今回A1 | 差分 |
|------|----------|--------|------|
| ROI | -5.07% | -36.04% | **-31%** |
| 実行スクリプト | run_ab_feature_test.py | run_day10_comprehensive.py | 異なる |
| final_balance取得 | ✅ 成功 | ❌ 失敗 | 差あり |
| ROI計算方式 | 資産ベース | 報酬ベース | **根本的に異なる** |
| Walk-Forward | 有効 | 無効 | 差あり |
| データ | Parquet | Parquet | 同一 |

**原因仮説**:
1. **ROI計算方式の違い**: 45# Day5は `(final_balance - initial) / initial × 100`、今回は `final_reward × 100`
2. **Walk-Forward有無**: 45# Day5は4 splits、今回は無効
3. **環境初期化の違い**: final_balance取得ロジックの差

### 2.2 50k vs 25kステップ比較

| g99, entauto | N/A | -27.59% (B4) | - |

**観察**: 50kステップで一貫して劣化。78# Day9bの発見（崩壊現象）と整合。

## 3. 根本的問題の整理

### 3.1 ROI計算の信頼性

```
問題: 全実験でfinal_balance取得失敗
     → ROI = final_reward × 100 は不正確
     → 45# Day5との比較が不可能

原因: run_day10_comprehensive.py の環境unwrapロジックに問題がある可能性
     または UnifiedTrainer の環境管理方法が変更された可能性

影響: 今回の全24実験のROI値は参考程度にしかならない
```

### 3.2 50kステップでの崩壊

```
現象: 25k → 50k で ROI が大幅に悪化
      - 75# Day9 (25k): -6.29%
      - 78# Day9b (50k): -36.83%
      - 今回A1 (50k): -36.04%

仮説:
1. 過学習: 同一データへの過剰適合
2. 方策崩壊: エントロピー低下による探索不足
3. 報酬ハッキング: 報酬関数の悪用を学習
4. 勾配消失/爆発: 長期学習での数値不安定
```

### 3.3 45# Day5との再現性問題

```
事実: 同一SAC_DEFAULT設定で31%のROI差
      - 45# Day5: -5.07%
      - 今回A1: -36.04%

可能性:
1. ROI計算方式の違い（最有力）
2. Walk-Forward有無の影響
3. 環境初期化シードの影響
4. ライブラリバージョン差
```
