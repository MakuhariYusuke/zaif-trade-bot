## 2. 損失の原因分析

### 2.1 取引コスト仮説

```
取引回数: ~260回 @ 50k steps
取引コスト: 0.1% / 取引
推定コスト: 260 × 0.1% = 26%（往復で半分としても13%）
```

**疑問点**: 取引コストだけで-5%を説明できるか？
→ 取引回数を減らせば改善する可能性

### 2.2 学習不足仮説

```
50kステップは不十分？
- 25k: ROI=-5.02%
- 50k: ROI=-5.24%
→ ステップ増加で悪化（過学習の兆候？）
```

### 2.3 報酬設計仮説

Day10 D2_stage2でROI≈0%となった（取引しなくなった）
→ 報酬のバランスが取引を抑制している可能性

### 2.4 ハイパーパラメータ仮説

Day10 C1でgamma=0.95でROI=-5.71%（若干悪化）
→ gammaの影響は小さいか、または正しく測定できていなかった

## 6. リスクと代替案

### 6.1 Phase 4.5で改善しない場合

1. **特徴量の見直し**
   - 現在84特徴量 → より予測力のある特徴量選定
   - 市場レジーム判定の精度向上

2. **データの見直し**
   - より長期のデータでの学習
   - 異なる市場状況での検証

3. **アルゴリズムの見直し**
   - SAC以外のアルゴリズム（PPO, TD3）
   - アンサンブル手法

4. **戦略の見直し**
   - RLベースからルールベースへの転換
   - ハイブリッド戦略（RL + ルール）

### 6.2 撤退基準

Phase 4.5で以下の状態が続く場合、アプローチの根本的見直しを検討：

- 10実験以上で改善なし
- ROIが-10%を下回る
- 取引パターンが崩壊（HOLDのみ、または極端な偏り）
