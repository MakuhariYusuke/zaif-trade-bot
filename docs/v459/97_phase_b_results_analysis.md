## 3. 多角的考察

### 3.1 最重要発見: Net ROI の驚くべき収束

**全8実験のNet ROIが-14.98%〜-15.05%の0.07%幅に収束している。**

これは偶然ではない。Net PnL ≈ -Fees であり、Gross PnLは相対的に小さい。つまり:

$$\text{Net PnL} = \underbrace{\text{Gross PnL}}_{\text{小さい}} - \underbrace{\text{Fees}}_{\text{支配的}} \approx -\text{Fees}$$

**解釈**: エージェントは報酬関数の設計に関わらず、ほぼ同じ「ランダムに近い取引行動」を学習し、手数料によって一定の損失を被っている。50Kステップでは戦略的な行動を学習できていない。

### 3.2 手数料構造の分析

- 平均取引回数: ~950回/50Kステップ → **53ステップ(分)/1取引**
- 平均手数料/取引: ~15,000 / 950 ≈ **15.8 JPY/取引**
- 50Kステップ ≈ 34.7日分（1分足）
- 1日あたり ~27取引 → **過剰取引**

**取引頻度に対するGross PnLの効率性**:
- P1-1: 389 JPY / 979取引 = **+0.40 JPY/取引**（手数料15.8 JPYに対し桁違いに小さい）
- P1-3: -306 JPY / 919取引 = **-0.33 JPY/取引**

手数料が利益の**約40倍**。どのような微小なα(超過収益)があっても手数料に完全に埋没する。

### 3.3 Gross PnLの評価（P1-1 vs P1-3）

P1-1のGross PnL平均は+389 JPYで、P1-3の-306 JPYより695 JPY良い。ただし:

- **P1-1の標準偏差は897 JPY** → 平均の2.3倍。統計的有意性は低い
- 4シード×2条件のWelch's t-test概算: t ≈ 695 / √(897²/4 + 361²/4) ≈ 695 / 486 ≈ **1.43** → p ≈ 0.20（有意でない）
- ただし、P1-1の**2/4シードが正のGross PnL**を示したことは、取引戦略が完全にランダムではない可能性を示唆

**批判的評価**: 50Kステップ/4シードでは結論は時期尚早。しかし「P1-1が僅かに良い方向を向いている」程度の評価は妥当。

### 3.4 BUY:SELL完全対称の異常性

全8実験でBUY数=SELL数が**完全に一致**している。これは:

1. **環境の制約**: ポジション管理がBUY→SELLのペアを強制している可能性
2. **エージェントの未学習**: 方向性バイアスを学習できず、均等に売買している
3. **HOLD行動の欠如**: 50,000ステップ中~950取引 = ~1,900 BUY/SELL行動 → **残り~48,100ステップはHOLD**

HOLDが96%を占め、残り4%が均等にBUY/SELLに分配されている。エージェントはほぼ何もしておらず、たまに「ランダムに」売買している。

### 3.5 `calculate_reward_simple()` の残存汚染（重要）

P1-1 (`use_simple_reward=True`) でも以下の非PnLコンポーネントが**依然アクティブ**:

```python
# reward_calculator.py L1289
if position_change > 0.1:  # ハードコード
    reward -= 0.1           # 常時適用、無効化不可

# L1293-1295
reward = self.dynamic_reward_shaper.shape_reward(...)   # 動的シェーピング
reward = self.asymmetric_reward_scaler.scale_reward(...) # 非対称スケーリング
```

| 残存コンポーネント | 影響 | 無効化方法 |
|---|---|---|
| `position_change > 0.1 → -0.1` | 全ポジション変更にペナルティ | コード修正のみ |
| `dynamic_reward_shaper` | 市場レジーム依存のシェーピング | `enabled=False`設定 |
| `asymmetric_reward_scaler` | 乗数=1.0で中立化済み | ✅ 設定で対応済み |
| `signal_integrator` | If enabled | 要確認 |

**→ P1-1は厳密には「純粋PnL」ではない。ハードコードペナルティとdynamic_reward_shaperが残存。**  
ただし、`asymmetric_reward_scaler`は乗数1.0で中立化されており、主要な汚染源はハードコードの`-0.1`ペナルティ。

### 3.6 50Kステップの十分性

| 比較基準 | 値 |
|---|---|
| 50Kステップ | 34.7日分データ |
| SACの典型的収束 | 100K-500K ステップ |
| 96#計画の本番設定 | Phase C以降で200K-500K予定 |

50Kステップは実質「早期探索段階」。SACのactor-criticが十分に収束するには短すぎる可能性がある。  
ただし、**ランダム行動と有意に異なる行動を学習できていないこと**自体が問題を示している。

### 3.7 西洋的強化学習への固執に対する疑義

深層強化学習（SAC）をBTC/JPY 1分足取引に適用することの根本的問題:

1. **信号対雑音比（SNR）**: 1分足のリターンはほぼホワイトノイズ。SACが学習できるα <手数料
2. **学習効率**: SACは連続行動空間に強いが、離散的な売買判断（BUY/SELL/HOLD）に変換する際に情報損失
3. **報酬遅延**: 取引の結果は即座に確定せず、報酬帰属の不正確さが学習を阻害
4. **代替手法の検討余地**:
   - ルールベース戦略（モメンタム、平均回帰）をベースラインとして比較
   - より長い時間足（5分、15分）での学習
   - 取引コストを環境内で明示的にモデル化（報酬からの間接的控除ではなく）
