# 79. Day 9b（50k検証）レビューと追加改善提案

**対象**: `docs/v459/78_day9b_50k_validation_results.md` / `results/phase4_day9_50k_validation/day9b_50k_validation_interim.json`  
**日付**: 2026-01-31  
**結論**: 50kでの悪化は「過学習」だけでは説明不足。**(1) ROI算出の妥当性、(2) 設定交絡の多さ、(3) 更新強度過多（lr×grad_steps×buffer）**が主要疑点。  
次の一手は「**45# Day5設定の厳密再現**」と「**評価指標の独立算出**」を最優先とするべき。

---

## 1. 重要な指摘（69〜78で未解決の点）

### 1) **ROIの根拠が薄い（estimated_roi_pct = final_reward×100の可能性）**
- interim JSONでは `final_reward=-0.5969` → `estimated_roi_pct=-59.69` の完全比例が確認できる。  
- これは**“ROI推定”ではなく“報酬の単純スケーリング”**であり、実ROIではない可能性が高い。  
**影響**: 「-36.83%」という結論自体が過大・過小評価の恐れ。  
**対応**: ポートフォリオ曲線から **ROI/Sharpe/MaxDDを独立算出**し、Final Rewardは補助指標扱いに降格。

### 2) **50kでの悪化は“学習更新強度”の副作用かもしれない**
- 設定は `lr=0.0005, batch=128, grad_steps=2, buffer=25k`。  
- 50kまで進むと、**更新回数とデータ再利用が過剰**になり、方策が不安定化しやすい。  
**対応**: grad_steps=1、buffer=100k、lr=0.0003 で 50k再検証。

### 3) **行動分布の変化は小さいが損失は劇的（=説明が不足）**
- 25k→50kでHOLDは-4.2pt程度、BUY/SELLも+2〜3pt程度。  
- 行動比率がほぼ同じなのに損失だけ拡大 → **“行動の質”が悪化**している可能性。  
**対応**: gross PnL / net PnL / per-trade PnL / turnover をログ化。

---

## 2. 50k悪化の現実的な原因仮説（優先度順）

1) **評価指標の誤解釈（ROIではなく報酬スケール）**  
2) **更新強度過多による方策崩壊**  
3) **報酬スケール/clipの実効反映の不整合**  
4) **探索不足ではなく“過剰取引の質悪化”**  
5) **walk-forward無効化による学習データ過適合**  

---

## 3. 改善提案（実行優先順）

### ✅ 最優先（評価の土台を固める）
1. **ROI/Sharpe/MaxDDを独立算出**  
   - portfolio_valueの履歴から計算し、`estimated_roi_pct` を廃止。  

2. **45# Day5設定の厳密再現（50k）**  
   - ent_coef=auto, batch=256, grad_steps=1, buffer=100k, lr=0.0003  
   - 50kで -5% 程度が再現できるか確認（再現性の基準点）

### ✅ 次点（交絡の除去）
3. **gamma×ent_coef 2×2（0.95/0.99 × 0.01/auto）**  
4. **batch/grad_steps ablation**（128↔256, 1↔2）  

### ✅ 構造改善（高収益化の条件）
5. **報酬構造の再設計（stage2活用）**  
   - 単純PnLではなく、リスク調整報酬や取引品質スコアを導入。  
6. **取引コストの可視化**  
   - gross/net差分、cost ratio、turnoverを常時記録。  

---

## 4. 追加で見落とされがちなポイント

- **reward_scale / reward_scaling / reward_clip の実効値**のログ化が必須。  
- **walk-forward無効化**により、学習データへの過適合が起きやすい。  
- **25k→50kの悪化がseed 42で極端**（-59.7%）なため、外れ値耐性（median評価）も併用すべき。  

---

## 5. 次ステップの推奨順位（現状の宿題を踏まえた順序）

1. **45# Day5設定の再現（50k）**  
2. **評価指標の独立算出**（ROI/Sharpe/MaxDD）  
3. **gamma×ent_coef 2×2 実験**  
4. **batch/grad_steps ablation**  
5. **stage2報酬設計の再導入**  

---

## 6. 最終判断

- 50kでの悪化は「ent_coef=0.01の失敗」と断定するには根拠不足。  
- まず評価指標と設定再現性を固めるべきで、**高収益モデル探索はまだ入口**。  
- 「損失最小化」から「収益最大化」へ軸を戻すため、**報酬構造の再設計が不可避**。
