# 49. 外部アドバイス回答（Phase 4 Day 5 以降の改善提案）

**対象**: `docs/v459/48_external_advice_request.md`  
**日付**: 2026-01-28  
**結論**: 現状の損失は**報酬設計の不均衡 + 過剰売買 + 取引コストの影響**が主因の可能性が高い。  
50,000ステップでも改善余地は十分あるが、**「報酬のスケーリング／ペナルティ調整」→「売買頻度の抑制」→「SACの探索バランス調整」**の順で詰めるのが最短。  

---

## 1. 現状診断（重要な兆候）

### 1.1 負報酬99%は異常に近い
負報酬比率が99.34%というのは、**報酬が「ほぼ常に罰則」になっている**状態。  
これは学習の阻害だけでなく、**ポリシーが“損失最小化”へ偏る**原因になりやすい。

### 1.2 SELL偏重は“報酬/コスト設計の歪み”のサイン
SELL偏重 + Strong Sellの比率が高いのは、  
**HOLDペナルティや取引コストの構造が学習を歪めている**可能性が高い。

### 1.3 取引コストの影響が過大
0.1%は**片道コスト**のため、往復で0.2%が基準。  
実際の摩擦は「取引回数 × 平均売買比率」に依存し、**頻度が高いほど構造的に不利**。  
つまり「売買頻度を抑える設計」が最重要。

---

## 2. 優先順位付き 改善策（効果 × 実装容易性）

### ✅ 優先1：報酬の再バランス（最重要・即効性）

**狙い**: “罰則だらけ”を解消し、正報酬を生む構造に戻す  

**具体案**:
1. **Holdペナルティを削除 or ほぼ0へ**
   - `-0.0001 → 0` か `-1e-5`
2. **Drawdownペナルティのスケール縮小**
   - `-10.0 → -1.0` もしくは `-0.5`
3. **報酬クリップ or スケーリング**
   - `reward = clip(reward, -1, 1)`  
   - もしくは `reward *= 0.1`
4. **二重ペナルティの回避**
   - 取引コストを「環境」で差し引くのか、「報酬」で引くのかを一本化

**期待効果**:  
正報酬比率の大幅増加、学習安定性向上

---

### ✅ 優先2：売買頻度の抑制（コスト負けの根本対策）

**狙い**: 取引回数の削減で損失構造を解消  

**具体案**:
1. **アクション変化ペナルティ**
   - `-k * |a_t - a_{t-1}|`（例: `k = 0.001`）
2. **最小保有期間（cooldown）**
   - 例: 「直近Nステップ以内の売買を禁止」
3. **デッドゾーン拡大**
   - HOLD範囲を `[-0.6,0.6] → [-0.7,0.7]` に拡張  
   - もしくは「action = target position」として**変化速度を制限**

**期待効果**:  
取引回数を半減できればROIは大幅改善の可能性

---

### ✅ 優先3：SAC探索バランスの調整（50kステップ向け）

**狙い**: 少ステップで収束しやすい方向に寄せる  

**具体案**（小規模A/Bで比較）:
- `learning_rate: 3e-4 → 5e-4`
- `ent_coef: auto → 0.01`
- `gamma: 0.99 → 0.95`
- `batch_size: 256 → 128`
- `gradient_steps: 1 → 2`

**期待効果**:  
探索過剰の抑制 + 早期収束

---

### ✅ 優先4：特徴量を“少し戻す”

**狙い**: 8特徴は軽量だが情報不足の可能性  

**追加候補（+4〜8特徴）**:
- トレンド傾き（短期MA vs 長期MA）
- ボラティリティ指標（ATR / 直近標準偏差）
- レジーム指標（レンジ/トレンド）

**理由**:  
レンジ相場で売り偏重になっているのは、  
**レンジ判定に必要な特徴が不足している可能性**が高い。

---

### ✅ 優先5：時間足 or 行動頻度の見直し

**狙い**: 1分足 + 0.1%コストはノイズ過多  

**現実的な対処**:
- 5分足 or 15分足へ再サンプリング  
  もしくは  
- **行動頻度を5分に制限**（データは1分、決定は5分ごと）

---

## 3. 最小A/Bテスト設計（短時間で効果検証）

**ステップ数**: 50,000  
**実験数**: 4パターン × 2 seed（最小構成）

| 実験 | 変更点 | 目的 |
|------|--------|------|
| A | 現状 | ベースライン |
| B | Hold削除 + Drawdown -1.0 | 報酬バランス |
| C | B + action change penalty | 取引抑制 |
| D | C + ent_coef=0.01 + gamma=0.95 | 早期収束 |

**判定指標**:
- ROI (>=0%)
- 取引回数（50%減なら成功）
- Positive reward ratio（10%以上）
- Win Rate / Sharpe

---

## 4. 追加チェック（見落とされがちな点）

1. **手数料の二重計上**
   - reward内のコストと環境内のコストが重複していないか  
2. **報酬スケール**
   - min = -10 が強すぎる可能性  
3. **Action→Position変換**
   - 極端なactionが実取引量を過剰に増やしていないか  

---

## 5. まとめ（最短で損益改善を狙うなら）

**最短ルート**:
1. **Holdペナルティ削除 + Drawdownスケール緩和**
2. **アクション変化ペナルティ導入**（売買頻度抑制）
3. **ent_coef固定 + gamma短期化**

この3点だけでも**取引回数減 + 報酬バランス改善**が起きやすく、  
50,000ステップでも損益分岐～軽微プラスが現実的になる。
