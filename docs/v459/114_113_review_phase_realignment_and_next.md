### §3.3 [HIGH] 50K ステップの構造的制約への考察不足

113# は 50K を暗黙の制約として受け入れているが、**50K が根本的に不十分である可能性を検討していない**:

- SAC のバッファサイズ = 100,000 (デフォルト)。50K ステップでは **バッファが半分しか埋まらない**
- 50K ステップ ≈ 34.7日分のデータ (1分足)。**1ヶ月強の相場のみで汎化を期待**
- v457.3 の Buy & Hold 成功 (+36M JPY) は **長期保有** — 50K で再現不可能な戦略クラス
- 106# は「50K で PF >= 1.05 を複数 seed で再現」を step 拡大条件としたが、**PF=0.999 が天井**

113# は「エッジの寿命が短い (10K→50K で崩れる)」と述べたが、**学習が不十分で 50K 時点のモデルが 10K 時点のモデルより劣化している（過学習）可能性**もある。これは「寿命」ではなく「学習量」の問題。

### §3.4 [MEDIUM] Momentum_RSI 超過が真のベンチマークとして不適切

ベースライン比較で Momentum_RSI の粗利が SAC を上回ったが、**Momentum_RSI 自体が Net ROI=-5.05% で大幅に負けている**。

- Momentum_RSI の粗利/取引 = +10.39 JPY、手数料/取引 = 17.02 JPY → **Net/取引 = -6.63 JPY**
- したがって Momentum_RSI も **コスト負け** している
- 「Momentum に粗利で負けている」は事実だが、**両方とも負けている** ので「Momentum を超えれば勝てる」とは限らない
- 真のベンチマークは **Net PnL > 0 を達成するモデル** であり、Momentum_RSI はそのベンチマークを満たしていない

### §3.5 [MEDIUM] 「戦略分解」の前に「問題の診断」が不足

113# は P0-P2 で解決策を提案しているが、**問題の正確な診断**が不十分:

1. **SAC は本当に「取引しない」ことを学んでいるのか？** → threshold=0.80 でも eval trades=31 (50K) は少ないが、学習中は 700+ trades 発生。方策が「HOLD 寄り」に収束しているのか、eval の threshold が高すぎるのかは別問題
2. **Gross PnL が負の本質**: 方向予測力がゼロなのか、タイミングが悪いのか、ポジションサイズが不適切なのか
3. **10K vs 50K の差**: 過学習なのか、市場レジーム変化なのか、データ依存なのか

### §3.6 [LOW] 既存インフラの活用レベルが低い

113# §4 で既存資産に言及しているが、`ztb/metrics/metrics.py` (1950行, 30+関数) の豊富さに比べて `run_phase_c.py` の KPI 計算は極めて簡素。`seasonality_analysis()`, `rolling_analysis()`, `drawdown_analysis()` 等は Phase E の診断に直接使える。

### §5.2 Q1 の具体実装（115# 補正: 多面的 IC 評価）

Q1 は単純な action-次足相関だけでは非線形・遅延効果を捉えにくい (115# §1 MEDIUM 指摘)。
以下の多面的 Information Coefficient (IC) で評価する:

1. **Horizon 分解**: 1分 / 5分 / 15分先の price_change との相関
2. **Action 強度 bin 別**: |action| を [0, 0.3), [0.3, 0.6), [0.6, 1.0] に分割し、bin ごとの avg_net_pnl を比較
3. **時間帯別**: JST 0-6, 6-12, 12-18, 18-24 の 4 セッション別 IC
4. **rank IC**: Spearman 順位相関で非線形効果を捕捉

```python
# 多面的 IC 評価の骨格
import numpy as np
from scipy.stats import spearmanr

def compute_multi_horizon_ic(actions, prices, horizons=[1, 5, 15]):
    results = {}
    for h in horizons:
        price_changes = prices[h:] - prices[:-h]
        acts = actions[:len(price_changes)]
        pearson = np.corrcoef(acts, price_changes)[0, 1]
        spearman, p_val = spearmanr(acts, price_changes)
        results[f"horizon_{h}"] = {
            "pearson_ic": pearson,
            "spearman_ic": spearman,
            "p_value": p_val,
        }
    return results
```
