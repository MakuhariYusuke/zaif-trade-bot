## 3. 分析：なぜ50kで劇的に悪化したか？

### 仮説1: 過学習（Overfitting）

| 証拠 | 詳細 |
|------|------|
| HOLD率低下 | 41.6% → 37.4%（-4.2pt）|
| 取引頻度増加 | BUY+SELL: 58.3% → 62.6% |
| 損失拡大 | 取引増加に比例して損失拡大 |

**解釈**: 
- 学習が進むにつれ「もっと取引すれば利益が出る」と誤学習
- 実際には取引コスト（0.1%）で損失拡大

### 仮説2: 報酬信号の問題

| 観察 | 詳細 |
|------|------|
| 25kでの学習 | 「適度にHOLD」を学習 |
| 50kでの学習 | 「HOLDより取引」に逸脱 |

**解釈**:
- `reward_scale=100` + `use_simple_reward=True` の組み合わせが不安定
- 学習が進むと「間違った方向」に最適化

### 仮説3: 45# Day5 との設定差（確認済み）

| 項目 | 45# Day5 (50k, -5%) | 78# Day9b (50k, -37%) |
|------|---------------------|----------------------|
| gamma | 0.99 | 0.99 |
| ent_coef | **auto** | **0.01** |
| batch_size | **256** | **128** |
| gradient_steps | **1** | **2** |
| buffer_size | **100000** | **25000** |
| learning_rate | **0.0003** | **0.0005** |
| reward_scale | なし（デフォルト） | 100.0 |
| use_simple_reward | なし（デフォルト） | True |
| walk_forward | **有効 (4 splits)** | **無効** |

**重大な発見**: 
- 45# Day5 は **SAC_DEFAULT** 設定（ent_coef=auto, batch=256, grad_steps=1）
- 78# Day9b は **SAC_TUNED** 派生設定（ent_coef=0.01, batch=128, grad_steps=2）
- **設定差が多すぎて、どれが主因か不明**

### 78# 50k validation の衝撃

| 設定 | Steps | ROI | 結論 |
|------|-------|-----|------|
| gamma=0.99, ent_coef=0.01 | 25k | -6.29% | 一時的に良好 |
| gamma=0.99, ent_coef=0.01 | **50k** | **-36.83%** | **過学習で崩壊** |

**新しい解釈**:
- 25k steps では「学習途中」の一時的に良い状態だった
- 50k steps まで学習を進めると「間違った方向」に収束
- **ent_coef=0.01 は探索不足で局所解に陥る**

## 5. 根本原因の特定

### 問題の構造

```
┌─────────────────────────────────────────────────────┐
│ 問題: 学習が進むほど損失が拡大                      │
├─────────────────────────────────────────────────────┤
│ 原因1: ent_coef=0.01 → 探索不足 → 局所解           │
│ 原因2: reward_scale=100 → 報酬信号が不安定         │
│ 原因3: use_simple_reward=True → PnL直接最適化の罠  │
│ 原因4: 取引コスト0.1% → 取引頻度↑で損失↑          │
└─────────────────────────────────────────────────────┘
```

### 45# Day5 が -5% だった理由（推測）

| 要因 | 45# Day5 | 78# Day9b |
|------|----------|-----------|
| ent_coef | auto（適応的探索） | 0.01（固定・探索不足）|
| 報酬設計 | デフォルト | use_simple_reward=True |

**45# Day5 の設定が実は「たまたま」良かった可能性**
