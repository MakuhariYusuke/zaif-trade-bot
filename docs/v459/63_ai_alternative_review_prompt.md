## 📋 目的
Day 6 報酬チューニング結果（62番分析）に対して、別のAIコーディングエージェントから**批判的視点**と**代替案**を取得する。意外な発見や見落としを検出するための構造化されたプロンプト。

## 🎯 プロンプト本文（そのままコピー可能）

```
# 強化学習 報酬設計 A/Bテスト結果のレビュー依頼

## 背景
BTC/JPY 自動取引ボットの強化学習（SAC: Soft Actor-Critic）において、報酬設計のA/Bテストを実施しました。5つの設定 × 2シード = 10実験を完走し、以下の結果を得ました。

## 実験結果サマリー

| 設定 | Final Reward (平均) | 改善率 | 主な変更点 |
|------|---------------------|--------|-----------|
| A (Baseline) | -1.01e-04 | — | デフォルト設定 |
| B (Stage1) | +1.00e-05 | +111% | reward_scale=100.0 |
| C (HoldRemoved) | +3.61e-04 | +458% | Hold撤廃, reward_clip=[-1,1] |
| D (TradeReduced) | +3.83e-04 | +479% | 取引抑制強化 |
| E (ExplorationTuned) | +1.52e-03 | +1604% | SAC探索パラメータ調整 |

## 勝者 E 設定の詳細

### SAC ハイパーパラメータ変更
- learning_rate: 0.0003 → **0.0005** (+67%)
- batch_size: 256 → **128** (半減)
- gamma: 0.99 → **0.95** (短期報酬重視)
- gradient_steps: 1 → **2** (学習効率2倍)
- ent_coef: "auto" → **0.01** (探索安定化)

### 報酬設計変更（累積）
- trading_bonus: 0.01 → 0.0 (Hold撤廃)
- hold_penalty_multiplier: 0.0 (Holdペナルティ撤廃)
- reward_clip: [-80,80] → [-1,1] (正規化)
- trade_frequency_penalty: 0.001 → 0.01 (10倍)
- action_smoothing: 0.0 → 0.01 (追加)

### アクション分布の変化
- A: HOLD=33.6%, BUY=33.7%, SELL=32.8%
- E: HOLD=35.8%, BUY=32.8%, SELL=31.5% (HOLD増、SELL減)

## 現在の分析結論

1. **ent_coef=0.01（固定）** が最重要: 探索の暴走を防止
2. **gamma=0.95** が重要: 短期報酬重視で学習安定化
3. **Hold撤廃 + reward_clip[-1,1]** が効果的
4. 取引抑制（D）より探索最適化（E）が重要

---

## レビュー依頼事項

### 1. 批判的検証（必須）
以下の点について、私の分析に**反論または疑問**を提示してください：

- [ ] Final Reward だけで評価していないか？他に見るべきメトリクスは？
- [ ] 2シードで統計的に有意と言えるか？
- [ ] gamma=0.95 は本当に最適か？短期すぎるリスクは？
- [ ] ent_coef=0.01 固定は過学習のリスクがないか？
- [ ] reward_clip=[-1,1] は情報損失を招いていないか？
- [ ] HOLD増加は本当に良いことか？取引機会損失は？

### 2. 見落とし検出（必須）
以下の観点で**見落としている可能性のある点**を指摘してください：

- [ ] 他のSACハイパーパラメータ（tau, buffer_size, learning_starts）は検討したか？
- [ ] 報酬設計の他の要素（sharpe_bonus, sortino_bonus）は無視して良いか？
- [ ] データの特性（トレンド、ボラティリティ）との相関は確認したか？
- [ ] 過学習の兆候（training vs validation の乖離）は確認したか？
- [ ] 取引コスト (0.1%) の影響は十分考慮されているか？

### 3. 代替アプローチ提案（任意）
以下の代替案について意見を求めます：

**代替案A: E-Lite 設定**
- gradient_steps: 2 → 1 (時間短縮)
- batch_size: 128 → 64 (さらに細かく)
- 期待: 時間67分→39分、効果80%維持

**代替案B: ハイブリッド設定**
- C設定の報酬設計 + E設定のSACパラメータ + gradient_steps=1

**代替案C: 段階的gamma**
- 初期: gamma=0.90 (超短期)
- 中期: gamma=0.95
- 後期: gamma=0.99 (長期収束)

### 4. 意外な発見を促す質問（重要）

以下の質問に回答してください。**直感に反する答えも歓迎**します：

1. **もしE設定が過学習だったら、どんな兆候が現れるか？**
2. **SELL比率31%は最適か？理論的な最適値は存在するか？**
3. **gamma=0.95 と ent_coef=0.01 のどちらがより重要か？片方だけ変えたらどうなるか？**
4. **reward_clip=[-1,1] ではなく [-0.5,0.5] や [-2,2] だったらどうなるか？**
5. **50,000ステップは十分か？収束判定の基準は？**
6. **BTC/JPY特有の市場特性を活かした設計は可能か？**

### 5. リスク評価（必須）

長時間トレーニング（100k〜500kステップ）を実行する前に、以下のリスクを評価してください：
