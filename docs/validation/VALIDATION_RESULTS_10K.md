## 🎯 問題点の整理

### **主要課題**
1. **Lambda上限到達**: 制約強度を最大まで引き上げたが、目標15%に届かず
2. **学習の不安定性**: ミニバッチにBUY/SELLが含まれないケースが頻発
3. **バッチ間の分散**: 最終バッチは18.8%だが、平均は10.7%

### **緊急修正の効果**
✅ **改善した点**:
- SELL率: 1.6% → 10.7% (6.7倍の改善)
- Lambda制約: 正常に動作 (上限まで活用)
- 最終バッチ: 18.8%達成 (目標15%を超過)

❌ **未達成の点**:
- 平均SELL率: 10.7% (目標15%に4.3ポイント不足)
- Lambda: 上限20.0到達 (これ以上の強化不可)

## 🔧 次の対策案

### **推奨アプローチ 1: Lambda上限の引き上げ**
```json
"lagrange_lambda_max": 30.0,  // 20.0 → 30.0
"lagrange_eta": 0.15,          // 0.1 → 0.15 (収束速度を向上)
```
**理由**: 現在Lambda=20.0で上限到達。より強い制約が必要。

### **推奨アプローチ 2: SELL報酬のさらなる強化**
```json
"profit_bonus_multipliers": [1.0, 1.0, 3.0],  // 2.0 → 3.0
"action_penalties": [0.0, 0.0, 0.0],          // ペナルティ完全撤廃
```
**理由**: 最終バッチで18.8%達成 → 報酬がより高ければ早期に学習可能。

### **推奨アプローチ 3: ミニバッチサイズの調整**
```json
"batch_size": 64,              // 32 → 64
"n_steps": 1024,               // 512 → 1024
```
**理由**: SELL頻度が低い状況では、より大きいバッチで多様性を確保。

### **推奨アプローチ 4: 層別サンプリングの強化**
```json
"enable_stratified_sampling": true,
"stratified_oversampling_rate": 3.0,  // 新規追加
```
**理由**: SELLサンプルを意図的にオーバーサンプリングして学習機会を増やす。
