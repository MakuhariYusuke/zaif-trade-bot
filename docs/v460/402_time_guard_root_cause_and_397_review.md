## 2. 根本原因の実証分析 (5,078 records, 1,249 fills)

### 2.1 AS率が時間帯パフォーマンスの最大ドライバー

```
UTC  JST  n    mean     AS%    buy_mean  sell_mean
 00   09  87  -2.171   59.8%   -0.261    -3.954    ← AS最悪、sell壊滅
 07   16  44  +1.775   34.1%   +2.103    +1.476    ← AS最良、最高益
 13   22  40  -1.891   62.5%   -1.922    -1.863    ← AS最悪2位
 18   03  68  +1.274   44.1%   -0.589    +2.929    ← sell好調
 20   05  54  +0.538   44.4%   +0.759    +0.281    ← low AS、安定
```

**結論**: AS率と時間帯平均PnLの間に **明確な負の相関** が存在する。
AS率50%超の時間帯は例外なく mean<0、AS率45%未満の時間帯は例外なく mean>0。

### 2.2 JST 09h (UTC 00) の深掘り — 最悪時間帯

| 指標 | 値 | 解釈 |
|------|---|------|
| AS率 | **59.8%** | 全時間帯で最悪 |
| sell mean | **−3.954 bps** | sell 壊滅 (WR=29%) |
| buy mean | −0.261 bps | buy は比較的無害 |
| worst fill | −51.90 bps | 単一 sell tail event |
| regime分布 | ranging 69%, trending_up 23%, trending_down 8% | |
| 主要 regime | trending_down: n=7, mean=−3.62 | 全敗 (WR=0%) |
| | trending_up: n=20, mean=−3.23 | sell AS (WR=45%) |
| spread | avg 2,644 JPY (全時間帯で最大) | spread 大 → AS リスク大 |

**根本原因**: 日本市場オープン (08:00-09:00 JST) 前後で**機関投資家の大口注文**が入り、
板の反対側（maker側）が逆選択される。spread が広がるのもこの時間帯の特徴。
特に **sell** が壊滅的 — 大口の買い注文に逆選択される構造。

### 2.3 構造因子の独立性テスト

| 因子 | 悪い方 | 良い方 | 差 | 根本性 |
|------|--------|--------|---|--------|
| **AS率** | ≥55%: mean=−1.14 | <45%: mean=+0.87 | 2.01 | **最高** |
| vol_ratio | ≥1.3: mean=−0.778 | <0.7: mean=+0.146 | 0.92 | 高 |
| OBI | <−0.3: mean=−0.421 | >+0.3: mean=+0.590 | 1.01 | 高 |
| spread | [2k,4k): mean=−0.239 | <2k: mean=+0.016 | 0.26 | 中 |
| confidence | ≥0.9: mean=−1.690 | [0.5,0.7): mean=−0.175 | 1.52 | **注意** ※ |

※ **重要警告**: 全データでは confidence ≥0.9 が mean=−1.690 で**最悪** — 395# の「[0.7,0.9) が問題」という結論は **全データでは逆転** している。395# の SHA-fenced 分析が特定 SHA の specificity だった可能性。

### 2.4 改修履歴との対応

| 過去改修 | 対象時間帯 | 根本原因 | 対策の根本性 |
|---------|-----------|---------|------------|
| 306#: sell_hour_boost UTC 08,13,14,16 | JST 17,22,23,01h | AS率 51-62% | ○ 症状対策 (AS を直接は修正しない) |

## 4. 根本原因への到達

### 4.1 時間帯 × PnL の真のメカニズム

```
日本市場オープン前後 (JST 08-10h)
  → 機関投資家の大口注文流入
    → 板の反対側への逆選択 (AS)
      → 特に sell maker が buy 大口に逆選択
        → sell tail event (−51.90 bps 等)
          → 時間帯平均を大幅に引き下げ

深夜帯 (JST 22-23h, JST 01h)
  → 流動性低下
    → AS率上昇 (62.5%)
      → buy/sell 両方が悪化
        → spread は平均以上だが AS 回避不能

午後帯 (JST 16h, 05h)
  → 適度な流動性
    → AS率低下 (34-44%)
      → maker が有利に fill
        → 安定した正リターン
```

### 4.2 「時間帯」は症状であり、根本原因は AS 構造

**過去の改修** (sell_hour_boost, hour_offsets, hard_skip) は全て **AS による逆選択という根本原因の症状** への対症療法。

根本的に address するには:
1. **AS 事前予測** — 時間帯だけでなく、リアルタイムの板構造・注文フロー・VPIN から AS 確率を推定
2. **AS 条件付き offset** — 「AS が高いからこの時間帯は offset を上げる」ではなく「AS 確率 > X% なら offset を上げる」
3. **Sell tail event 防御** — 単一大損失の回避（loss_cooldown, dynamic_kill は既に存在するが、事前防御が弱い）

### 4.3 395# → 397# 結論の修正

| 395# 結論 | 全データ検証結果 | 修正 |
|-----------|---------------|------|
| confidence [0.7,0.9) が唯一の構造的問題 | 全データでは [0.7,0.9) は mean=+0.123 (正) | **SHA-specific だった可能性大** |
| confidence ≥0.9 は良好 | 全データでは ≥0.9 が mean=**−1.690** で最悪 | **見落とし (n=52で有意)** |
| 397# offset ×1.2 で改善見込み | sell 側は ceiling 制約でほぼ無効 | **sell はceilingに到達済で効果なし** |
