> **A が圧倒的に安定**。全メトリクスで最小 range/CV。B は corr で CV=2.17 と極端に不安定。C は ROI の CV=1.90 で実質ノイズ。

### §5.2 Cross-Experiment Seed 一貫性

| Seed | A ROI% | B ROI% | C ROI% | A rank | B rank | C rank |
|---|---|---|---|---|---|---|
| 42 | 0.690 | 0.658 | -0.057 | 1 | 1 | 3 |
| 123 | 0.637 | 0.217 | 0.191 | 2 | 3 | 2 |
| 456 | 0.332 | 0.158 | **0.713** | 4 | 4 | **1** |
| 789 | 0.550 | 0.548 | -0.144 | 3 | 2 | 4 |

Kendall tau (ランク相関):
- A vs B: τ=0.667 (p=0.333) — **正の一貫性** (seed42 が両方で 1 位)
- A vs C: τ=-0.333 (p=0.750) — **逆転** (seed456 が A で最下位 → C で 1 位)
- B vs C: τ=-0.667 (p=0.333) — **逆転傾向**

> **重要発見**: seed456 は A/B では最悪 (低 ROI, 低 PF, 負/低 corr) だが、C では突出して最高 (ROI=0.71%, corr=0.81)。
> これは weight_decay が seed456 の過学習を効果的に抑制した一方、他の seed では学習能力を過剰に制約した可能性を示唆する。
> → **Weight decay の効果は seed 依存的であり、一律適用は危険**。

## §7 仮説検証

### H1: M1 (net_arch 縮小) は 20K で性能改善するか?

| | A [256,256] | B [128,128] | Delta |
|---|---|---|---|
| ROI median | 0.594% | 0.382% | **-0.212%** |
| PF median | 1.145 | 1.121 | -0.024 |
| Sharpe median | 5.702 | 3.883 | -1.819 |

**判定: 棄却** — M1 は 20K では全メトリクスで劣化。411# の仮説「過パラメータ化の解消で安定化」は 20K データ量では当てはまらない。

**考察**: 20K / 215K = 10.8x の ratio は「過パラメータ化」ではなく「記憶容量の活用」として機能している可能性。学習データが限られる場合、大きなネットワークは train data を効率的に記憶でき、OOS でも（分布が大きく変わらない限り）有効に動作する。

### H2: M2 (weight_decay) は alignment (corr) を改善するか?

| | B (M1, wd=0) | C (M1+M2, wd=1e-4) | Delta |
|---|---|---|---|
| Corr median | 0.231 | 0.432 | **+0.201** |
| Corr mean | 0.171 | 0.507 | **+0.336** |
| Corr std | 0.371 | 0.184 | **-0.187** |

**判定: 支持** — Weight decay は corr を改善し、かつ corr のばらつきを半減させた。正則化が reward-profit alignment を安定化する効果は明確。

### H3: Weight decay は収益を犠牲にするか?

| | B (wd=0) | C (wd=1e-4) | Delta |
|---|---|---|---|
| ROI median | 0.382% | 0.067% | **-0.316%** |
| PF median | 1.121 | 1.011 | **-0.110** |

**判定: 支持** — ROI が 82% 減少。Weight decay は 20K では収益を大幅に犠牲にする。alignment 改善と収益維持の両立は 20K では達成できない。

### H4: 20K では overparameterization が有利か?

| | A (ratio=10.8x) | B (ratio=2.9x) |
|---|---|---|
| ROI median | 0.594% | 0.382% |
| ROI CV | 0.25 | 0.54 |
| Sharpe median | 5.702 | 3.883 |

**判定: 支持** — 大きなネットワークが 20K では有利。記憶容量 > 汎化圧の構図。

### H5: Corr 向上と ROI 向上はトレードオフか?

| | Corr mean | ROI mean |
|---|---|---|
| A | 0.376 | 0.552% |
| B | 0.171 | 0.395% |
| C | 0.507 | 0.176% |

Experiment-level corr(alignment, ROI) = **-0.47** (弱〜中の負相関)

**判定: 条件付き支持** — 20K では alignment 改善が収益低下を伴う傾向がある。ただし相関 -0.47 は決定的ではなく、100K でデータが増えれば解消される可能性がある。

**補足**: B は A より corr が低い (0.171 vs 0.376) にもかかわらず ROI も低い → corr-ROI トレードオフではなく、**net_arch 縮小が両方を劣化させた**ケース。真のトレードオフは B→C の weight_decay 追加で観察される。

## §10 100K 投影と方針

### §10.1 パラメータ効率比 @100K

| Config | Params | Ratio @100K | 評価 |
|---|---|---|---|
| A [256,256] | 215K | **2.15x** | ✅ 適正 (sweet spot) |
| B [128,128] | 58K | 0.58x | ⚠️ 不足リスク (underfitting) |
| C [128,128]+wd | 58K | 0.58x | ❌ 不足 + 正則化で二重制約 |

### §10.2 20K→100K 外挿根拠

1. **A**: 20K で全メトリクス最強・最安定の G3 PASS。100K では ratio 10.8x→2.15x で **汎化向上期待**。記憶ベース戦略 → データ増で真の汎化に移行する最良候補。
2. **B**: 20K で G3 PASS だが margin 不足 (pf_worst margin=+0.08)。100K では ratio 0.58x で **capacity 限界** — データ量がネットワーク表現力を超え、学習曲線が飽和するリスク。
3. **C**: 20K で G3 FAIL。100K でも ratio 不足 + wd 制約のダブルパンチで **回復は困難**。

### §10.3 意思決定マトリクス

| Config | 20K G3 | 100K ratio | リスク | 期待値 | 推奨 |
|---|---|---|---|---|---|
| A | PASS | 2.15x | 低 | 高 | ◎ |
| B | PASS | 0.58x | 中 | 中 | △ |
| C | FAIL | 0.58x | 高 | 低 | × |

### §10.4 結論

**A (Baseline [256,256]) で 100K 単独実施を推奨**。

根拠:
1. 20K で最強の G3 PASS — 全 4 seed でプラス ROI、PF margin +0.095
2. 100K で ratio 2.15x — overparameterization が解消し汎化向上が期待される
3. Seed 安定性最高 — ROI CV=0.25、Sharpe CV=0.24
4. 100K で B を並行すると計算時間 2 倍だがスケールメリット (ratio 0.58x) が見込めない

## §11 発見と教訓

### §11.1 予想に反する発見

1. **Overparameterization は 20K では有害ではなかった** — 411# の仮説 (ratio 10.8x が seed 感度の原因) は定量的に否定された。大きなネットワークはデータを効率的に記憶し、OOS でも安定して機能した。

2. **Weight decay は corr を改善するが ROI を大幅に犠牲にする** — alignment と profitability のトレードオフが 20K では顕著。413# Gemini の「Q 値平滑化リスク」仮説を支持する結果。

3. **Seed sensitivity は net_arch 縮小で悪化した** — B の ROI CV=0.54 は A の 0.25 の 2 倍以上。小さなネットワークは初期条件への依存が増す。

4. **Weight decay の効果は seed 依存的** — C の seed456 は weight_decay の恩恵を最大限に受けた (corr=0.81, ROI=0.71%) が、seed42/789 では負 ROI。一律適用は危険。

### §11.2 412#/413# レビュー指摘の検証結果

| 指摘 | 結果 | 整合性 |
|---|---|---|
| 412# 「[128,128] が最適と断定するには時期尚早」 | **的中** — 20K では baseline に及ばない | ✅ |
| 412# 「M1/M2/M3 を分離テストすべき」 | **実施済み** — attribution 判明 | ✅ |
| 413# 「weight_decay は Q 値平滑化リスク」 | **支持** — ROI 大幅劣化 | ✅ |
| 413# 「Reward Hacking 仮説 (seed456)」 | **部分支持** — seed456 は A で低 corr だが C で高 corr | ⚠️ |

### §11.3 今後の検討事項

1. **A 100K 完了後に G3.1-stress** — slippage 1tick, maker miss 30% での耐性検証
2. **100K 結果を踏まえた M1 再検討** — ratio 2.15x でも seed 感度が残る場合、問題は ratio ではなく別の要因
3. **Weight decay の粒度調整** — wd=1e-4 は強すぎた可能性。wd=1e-5 や actor/critic 非対称 wd (412# §3.3 提案) の検討
4. **Corr-ROI トレードオフの 100K での確認** — データ増でトレードオフが解消されるか注視
