## 2. 根本原因分析

### 2.1 SkipGate スコア反転 (CRITICAL)

**buy の SkipGate スコアと PnL が逆相関**している:

| Score Band | Skip% | Pass 件数 | Pass PnL30 | 判定 |
|---|---|---|---|---|
| **< -3 (最低)** | 42.9% | 300 | **+0.24** | ✅ 実は最良 |
| -3 〜 -1 | 65.7% | 109 | -0.64 | ❌ |
| -1 〜 0 | 52.4% | 119 | -0.07 | △ |
| 0 〜 1 | 28.3% | 175 | -0.47 | ❌ |
| **> 1 (最高)** | 22.9% | 326 | **-0.57** | ❌ 最悪 |

**解釈**: モデルが「良い」と判断する (score>1) トレードは実際にはPnL=-0.57bpsと最悪。  
逆に「悪い」と判断する (score<-3) トレードのPnL=+0.24bpsが最良。  
→ **buy primary model (pnl30) のスコア方向が事実上反転している**

Score vs Threshold 分析も同様の反転を示す:

| マージン | PnL30 | AS% | n |
|---|---|---|---|
| below_threshold (skip済) | +0.16 | 36.1% | 424 |
| just_above (0-0.5) | **-1.49** | 45.9% | 85 |
| above (0.5-2) | +0.01 | 37.8% | 246 |
| well_above (>2) | -0.80 | 44.9% | 272 |

**閾値ギリギリで PASS したトレードが最も有毒 (-1.49bps)**
