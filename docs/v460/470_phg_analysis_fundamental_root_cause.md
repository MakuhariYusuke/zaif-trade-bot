# 470# 根本原因分析：なぜBotは構造的に負けるのか

## Executive Summary

3/16-3/18の1,342レコード（192約定、1,150未約定）を多角的に分析した結果、**損失の根本原因は特定時刻・レジームではなく、売り側オフセット設計の構造的バグ**であることが判明した。

核心：**「オフセットを上げる＝防御的」と設計されたパイプラインが、実際には「オフセットを上げる＝midに近づく＝攻撃的」という逆の効果を持つ。売りガードの`offset_floor: 0.30`が売りを強制的に攻撃的にし、パイプラインの全ブーストが逆方向に作用している。**

## 2. 根本原因の階層構造

### 2.1 [致命的] 売りオフセットのセマンティック反転

**これが全損失の最大原因。**

#### 価格計算の仕組み
```
buy_price  = best_bid + offset_jpy   (bidからmidに向かって移動)
sell_price = best_ask - offset_jpy   (askからmidに向かって移動)
offset_jpy = spread × offset_ratio
```

**offset_ratioが大きい = midに近い = 攻撃的 = 保護が薄い**

#### 実際の配置とその結果

| | Buy（base 0.05, ceiling 0.20） | Sell（base 0.18, pipeline→0.49, ceiling 0.50） |
|---|---|---|
| 注文時のmidからの距離 | 678 JPY（安全圏） | **187 JPY（危険圏）** |
| 待機中のmid逆行量 | 778 JPY | **936 JPY** |
| 約定時のmidとの位置関係 | mid+100（やや水面下） | **mid-750（完全に水没）** |
| 水没率（約定時にmid超え） | 55% | **66%** |
| BBO-to-mid浸透率 | 63.6% | **84.9%** |
| スプレッド獲得 | -0.11 bps | **-0.64 bps（壊滅的）** |

#### 数値で見る構造的破綻

```
売りの最終オフセット = 0.49 × 2,393 = 1,173 JPY (askからmid方向へ)
売り注文価格 = ask - 1,173 = mid + 1,196 - 1,173 = mid + 23 JPY ← ほぼmid!

平均逆行: 936 JPY
最終ポジション: 23 - 936 = -913 JPY ← mid下で約定（= 損失確定）
```

対して買い:
```
買いの最終オフセット = 0.20 × 2,393 = 479 JPY (bidからmid方向へ、ceiling適用)
買い注文価格 = bid + 479 = mid - 1,196 + 479 = mid - 717 JPY ← midから十分離れている

平均逆行: 778 JPY  
最終ポジション: 717 - 778 = -61 JPY ← ギリギリだが売りほど壊滅的ではない
```

#### なぜこうなったか：設計の逆転

パイプラインの各段（EV重み付け → velocity → trending_sell → toxicity → VG_supplement → macro_boost → alert_mode → sidecar → final_clamp）は全て**乗算ブースト**を適用する。1.0以上の値で「防御を強化」するつもりが、実際にはmidに向かって注文を押し込み、保護を薄くしている。

さらに`sell_guard.offset_floor: 0.30`が**「売りは最低でもスプレッドの30%分midに寄せろ」**と強制する。これは保護の下限のつもりが、攻撃性の下限として作用している。

**全ての「防御的」ブーストが逆方向に効いている。**

#### 売り注文の距離分布（注文時、midからの距離）

| 距離 | 件数 | 割合 |
|------|------|------|
| 0-100 JPY（ほぼmid） | 54 | **56.8%** |
| 100-300 JPY | 13 | 13.7% |
| 300-500 JPY | 18 | 18.9% |
| 500-1000 JPY | 9 | 9.5% |

**57%の売りが100JPY未満のバッファでmid直上に配置されている。**

### 2.2 [重大] EVモデルの売り側崩壊

| | Buy | Sell |
|---|---|---|
| ユニークEV値 | 92 | **9** |
| 最頻EV値 | 多様 | **-0.78（ほぼ全て）** |
| EV予測精度 | 反相関 | **定数（無意味）** |

- EVモデルの出力が売り側で**縮退**しており、事実上定数（-0.78）を返している
- 買い側も反相関（EV高→PnL低、EV低→PnL高）で予測力がない
- EV Q4（最高EV）: PnL=-1.1, WR=44%, 大損=27%
- EV Q1（最低EV）: PnL=+1.6, WR=51%, 大損=29%

**EVモデルは買い売り両方で信号として使用不能。売りでは完全に破綻。**

---

### 2.3 [重大] フィルタリングの致命的非対称

| フィルタ | Buy影響 | Sell影響 |
|----------|---------|---------|
| ranging_low_vol_skip | **520回**（全未約定の45%） | **0回** |
| 約定率 | 10.2% | **26.5%** |
| 結果 | 品質の高い機会のみ通過 | **全機会が無差別に通過** |

- `skip_ranging_buy_low_vol: true`が設定されているが、売り側には同等のフィルタがない
- 買いは厳選された10%のみ約定（品質管理あり）
- 売りは26.5%が約定（品質管理なし＋オフセットが攻撃的＝最悪の組み合わせ）

---

### 2.4 [構造的] 逆選択（Adverse Selection）の支配

マーケットメイキングの本質的課題として、逆選択が顕著に発生している:

| 待機時間 | 逆選択率 | PnL |
|----------|---------|-----|
| < 10秒 | **34.3%** | -0.4 bps |
| ≥ 10秒 | 21.5% | +0.2 bps |

**即座に約定する注文 = 情報を持ったトレーダーに拾われている**（Glosten-Milgromモデルと一致）

mid逆行の統計:
- Buy: 74%の約定で待機中にmidが下落（平均逆行: -1,689 JPY）
- Sell: 68%の約定で待機中にmidが上昇（平均逆行: +1,992 JPY）

**逆行が9割のフィルで発生し、その規模がオフセットの保護幅を大幅に超える。**

---

### 2.5 [構造的] 理論エッジと実現PnLの乖離

```
理論ハーフスプレッド: 1,196 JPY/fill (1.01 bps)
実現PnL:             -0.1 JPY/fill
理論エッジの活用率:   0.0% ← ゼロ
エッジ消失量:         1,197 JPY/fill
```

**スプレッドから得られるはずの理論エッジの100%が逆選択・オフセット過剰で消失している。**

---

### 2.6 [重要] レジーム別パフォーマンス

| レジーム | 件数 | PnL(bps) | 勝率 |
|----------|------|-----------|------|
| ranging | 80 | +0.2 | 54% |
| trending_up | 66 | **-2.1** | **35%** |
| trending_down | 28 | **-2.5** | **36%** |

- レンジ相場では微小ながら正のエッジ（マーケットメイキングの本質）
- トレンド相場で壊滅的損失 → **トレンド検知は機能しているが、対策（オフセットブースト）が逆効果**

---

### 2.7 [参考] 平均回帰の兆候

| 側 | 30秒PnL | 60秒PnL | 120秒PnL |
|------|---------|---------|----------|
| Buy | 0.1 | 1.1 | 0.9 |
| Sell | -0.3 | 0.6 | 0.2 |

- 30秒では逆選択が支配的（特に売り）
- 60秒で反転の兆候 → **逆選択は一時的で、平均回帰する可能性がある**
- ただし120秒で効果減衰 → 回帰は完全ではない

## 3. 因果関係の構造図

```
sell_guard.offset_floor: 0.30 ──→ 売りオフセット最低0.30を強制
         │
         ▼
パイプライン9段のブースト ──→ 0.30 → 0.49まで増幅
         │
         ▼
売り注文がmid+23JPYに配置 ──→ midのほぼ真上
         │
         ▼
情報持ちトレーダーがmid上昇時に拾う ──→ 936JPY逆行
         │
         ▼
約定時: mid-750JPYで売り約定 ──→ スプレッド獲得 = -0.64 bps
         │
         ▼
EVモデル縮退(定数-0.78) ──→ フィルタリング不能
         │
         ▼
ranging_low_vol_skip=売り側なし ──→ 品質管理なし
         │
         ▼
全てが通過 → 損失蓄積
```

## 4. 市場理論的考察

### 4.1 Glosten-Milgrom情報非対称モデル
当Botは教科書的な逆選択被害者。情報を持つトレーダーがmid移動を予見して当Botの注文を拾い、無情報トレーダーは当Botの注文に到達しない（スプレッド内に配置されているため）。

### 4.2 スプレッド内ペニング問題  
BBO内にリミット注文を配置する（「ペニング」）と、最良気配の先頭に立つ。これは情報トレーダーの最初の標的になることを意味する。売り側のオフセット0.49は事実上ペニングの極致。

### 4.3 Queue Priority vs. Information Risk
- 低オフセット(BBOに近い) = キュー後方 → 約定率低いが逆選択も低い
- 高オフセット(midに近い) = キュー最前/新規気配 → 約定率高いが逆選択最大
- 現在の売り側は後者の極致（26.5%の高約定率 + 最大逆選択 = 最悪の組み合わせ）

### 4.4 Maker's Dilemma
「約定率を上げたい」と「逆選択を避けたい」はマーケットメイカーの本質的トレードオフ。現設計は約定率を最大化する方向に全振りしており、逆選択コストを完全に無視している。

## 5. 改善提案（優先順位順）

### P0: 売りオフセットのセマンティクス修正 [緊急]

**問題:** パイプラインのブースト方向が意図と逆

**A案: 売りオフセットパラメータの抜本的修正**
```yaml
# 現在
side_offset.sell: 0.18
offset_ceiling_ratio_sell: 0.50
sell_guard.offset_floor: 0.30

# 修正案
side_offset.sell: 0.05           # 買いと同じベース
offset_ceiling_ratio_sell: 0.20  # 買いと同じシーリング
sell_guard.offset_floor: 0.02    # 最低限の侵入のみ許可（または無効化）
```
- 買い側と同等の保護（約678 JPY from mid）を売り側にも付与
- 約定率は低下（26.5% → 推定10-15%）するが、1約定あたりPnLが改善
- **理論上、スプレッド獲得が -0.64bps → +0.5bps以上に改善する可能性**

**B案: offset_ratio のセマンティクス反転**
- 「midからの距離」として再定義（値が大きい = 保守的）
- パイプラインのブースト方向が設計意図に一致
- 大規模なコード変更が必要、中期的に検討

### P1: EVモデルの売り側修正 [高]

**問題:** 売りEVが定数-0.78に縮退

**対策:**
- 売り側のEVウェイト(`ev_weighted_w30`, `ev_weighted_w120`)を一時的に0にする
- または EV入力の正規化・側別パラメータ化を検討
- EV予測が反相関のため、**EVによるオフセット調整を無効化**するのも有効

### P2: 売り側フィルタリングの追加 [高]

**問題:** ranging_low_vol_skipが買い側のみ

**対策:**
```yaml
# 売り側にも低ボラ・レンジスキップを適用
skip_ranging_sell_low_vol: true
```
- 品質の低い機会（低ボラ + レンジ + 売り）をスキップ
- 買い側と同等のフィルタリング品質を確保

### P3: 逆選択シグナルの活用 [中]

**問題:** 即座約定 = 情報トレーダーに拾われた可能性高

**対策:**
- 注文配置後のmid移動をモニタリング
- midが逆方向に一定量（例: 500 JPY）移動したら即キャンセル
- 現在リプライス実績が0件 → キャンセル＆再配置のロジック追加

### P4: 保持時間の最適化 [低-中]

**観察:** 30秒PnLは逆選択に支配されるが、60-120秒で部分的に回帰

**対策:**
- `post_fill_wait_sec`を60-90秒に延長
- またはPnL測定のみ長期化し、次サイクル開始は現行通り

## 7. 結論

**Botが負けている根本原因は「売りオフセットのセマンティック反転」という単一の構造的バグに帰着する。**

パイプラインの全段ブースト・セルガード・時間帯ブーストは全て「オフセットを上げる＝保守的」という仮定で設計されているが、実際の価格計算では「オフセットを上げる＝midに近づく＝攻撃的」である。結果として:

1. 売り注文がmidのほぼ真上に配置（mid + 23 JPY）
2. 936 JPYの逆行で即座に水没
3. スプレッド獲得が-0.64bps（負値）
4. 理論エッジ1,196 JPYの100%が消失

P0（売りオフセットの縮小）を即座に実施することで、最も大きな改善が期待される。
