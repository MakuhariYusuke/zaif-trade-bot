## §3 Seed 選定根拠

### 推奨: **Seed 456** (`sac_v460_seed456_best.zip`)

1. **最高 OOS ROI**: +0.60% (全シード中トップ)
2. **全チェックポイントOOS正**: 10/10 (123 も同等だが ROI が低い)
3. **後半スライス唯一 PF>1**: Late PF=1.187 — 他シードはすべて late で PF<1 に崩壊
4. **Sharpe**: 6.21 (全シード最高)
5. **MaxDD**: 0.25% (全シード最小)

### 次点: Seed 789

- OOS ROI は高い (+0.59%) だが、OOS 安定性が 2/10 と低い
- F6 best が 100K steps（最後に偶然改善）— 信頼性に疑問

### Seed 42 について

- Best CP = 10K で以降すべて OOS 負 → 早期収束型
- 「10万もやる必要なかった」はこのシードに限れば正しい
- **ただし Seed 123/456 は 90K でベスト** → 100K steps は無駄ではなかった

## §5 G3-pnl 自動評価

- **結果**: FAIL
- **理由**: `val_ratio=0.02 < min_val_ratio=0.10` — G3 PASS は val_ratio≥0.10 でのみ有効 (000# §3.5)
- これは想定どおり。val_ratio=0.02 の極小 OOS は F6 best-checkpoint 選定用であり、G3 合否判定には不十分

## §6 収束分析

- `roi_variance_pct_after_30k`: 0.177 — 30K 以降の ROI 分散は低い
- Seed 42 を除く 3 シードは 30K 以降もゆるやかに OOS 改善する「遅延収束」型
- **結論**: この config (reward_clean, val_ratio=0.02) では 50K-100K の範囲が最適
  - 10K: 初期探索のみ（Seed 42 はここで偶然良い局所解に着地）
  - 30K: 最低限の学習域
  - 90K-100K: 成熟域（456=90K, 789=100K, 123=90K）
