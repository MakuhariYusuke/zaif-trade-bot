### 補足コンテキスト

レビューに際して知っておくべき追加情報:

- **SkipGate**: LightGBM ベースの Adverse Selection 予測フィルター。
  fill_test の各サイクルで「この注文は AS に遭いやすいか」を予測し、
  閾値を超えたら注文をスキップする。現在 buy のみ有効 (sell は逆選別のため無効)。
  特徴量 16 個 (price 系, spread 系, volatility 系, time 系, side 系)。
  
- **fill_test**: maker-only 指値注文の実市場テスト。120s サイクルで
  板情報取得 → 価格算出 → 注文 → timeout 監視 → 約定判定 → PnL 計測。
  168h (7日間) 連続運行が Gate 判定の単位。

- **Adverse Selection (AS)**: 指値注文が約定した後、価格が注文者に不利な方向に
  動くこと。PnL30s < 0 の主因。maker 戦略の根本的な課題。

- **Gate 判定**: フェーズ移行の合否基準。12 チェック (fill_rate, PnL horizons,
  AS ratio, skip effectiveness, queue wait 等) の全 PASS が必要。
  WATCH = 条件付き通過 (minor watch 項目あり)。

- **000# (プロジェクト提案書)**: 全体のフェーズ定義 (ph1-ph5) と Gate 定義を規定。
  ph2 = fill_test 運用フェーズ、ph3 = SAC 4-seed ML 訓練フェーズ。

- **118# (バックログ深層分析)**: 1076 行の網羅的バックログ分析。
  120+ セッションから 53 OPEN items を抽出・分類。本ドキュメントの主要入力。

- **板情報 (OB)**: Coincheck の order_books API から取得する bid/ask の
  価格・数量リスト (depth=10)。マイクロストラクチャ分析の基盤データ。
  070#-072# で一度無効化された経緯がある。

- **SAC (Soft Actor-Critic)**: 強化学習アルゴリズム。
  ph3 で {buy, sell, hold} の action space で訓練予定。
