## §3 真のブロッカー — 三つの構造的問題

### 問題 A: Per-fill PnL が負 (avg ≈ -0.54 bps)

**これが最大の問題。** 669# の PI 改善は fill rate を上げるが、1 fill あたりの期待値が負なら、fill 数を増やすほど損失が増える。

**原因候補** (605# §0.2 + 現在のデータから):
1. **逆選択 (Adverse Selection)**: fill した瞬間に市場が逆行。maker の宿命だが、offset pipeline で緩和すべき
2. **offset pipeline の実効性**: ceiling 飽和は 565# で 0.35/0.40 に解消済み。だが avg PnL 負が続く → pipeline の出力するオフセットが逆選択コストを十分にカバーしていない
3. **EV toxic skip threshold が緩すぎる**: 現行 -8.0 (605# 提案は -5.0)。tail loss 帯域の fill を許容している

### 問題 B: NFQ (no_feasible_quote) の急増

3/27 以降 NFQ が 97→197→114→124→58 と高止まり。

**原因候補**:
1. 市場スプレッドの構造的縮小 → `min_spread_jpy` が相対的に高すぎて注文が出せない
2. ATR 連動 (`min_spread_atr_enabled: true`) が機能しているなら、ATR 自体が低下した可能性

### 問題 C: Alpha 層の実効寄与 ≈ 0

605# が既に指摘: SAC active ~8% (TTL 修正で改善済みだが) → ±0.15 bps 制限。
0# §0.1: 「SAC は助言者」。だが現状はその助言すらほぼ機能していない。

### P0 について

**EV toxic skip -8.0 → -5.0**: 現行の -8.0 は 605# の提案値 -5.0 より 60% 緩い。EV が -5.0 ~ -8.0 bps の範囲の「やや不利だが閾値に届かない」fill が通過している。これらが avg PnL を引き下げている可能性。

**NFQ 調査**: 3/20 (NFQ=0, fill 52.6%) と 3/28 (NFQ=197, fill 5.8%) の差異を生んだ市場条件を特定する。min_spread_jpy の ATR 連動が適切に機能しているかの検証。

### 不要なもの

- BALS, JPY Reserve, Edge-Gated Expansion — 全て保留。22,000 JPY 資本で理論的最適化は時期尚早
- Tier 3 施策 (A-S, SAC action 幅拡大) — avg PnL が正に転じるまで着手しない

## §6 自戒

663#-669# は「PI 45% が目に付いたから PI を直す」という症状治療に終始した。

PI を直しても avg PnL が -0.54 bps なら、fill が増えるほど損失が増える。
**一番痛い問題 (avg PnL 負) から逃げて、見えやすい問題 (PI) に飛びついた。**

渙三爻の教えは「自分の身を散らす」— つまり自分が向き合いやすい問題ではなく、向き合いたくない問題に向き合うこと。

avg PnL が負であることを直視し、Execution 層の改善に正面から取り組む。
