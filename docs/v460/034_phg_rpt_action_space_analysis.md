## 2. 行動空間拡張の全史

### 2.1 バージョン別変遷

| 世代 | Action Space | 拡張の試み | 結果 | 教訓 |
|------|-------------|-----------|------|------|
| v434 | 連続 1D | カリキュラム + アンサンブル + オンライン全部盛り | DUMMY だらけ、未動作 | 設計の壮大さ ≠ 実装の完成度 |
| v439 | 連続 1D | action_threshold 0.1→0.01 引下げ + ActionSignalGuide | 取引頻度は増加したが収益改善なし | 閾値操作は次元拡張なしでも行動分布を変えられる |
| v444 | 連続 + レジーム別サイズ倍率 | 16 レジーム × 5 パラメータ = 80 ハイパラ | 常に同じ Action 出力（100% BUY） | レジーム分類を増やしてもモデルの予測力が不足なら浮く |
| v445 | 連続 + MTF + 動的閾値 | 12 レジーム + 閾値適応 | レジーム検知器が不正確で機能せず | 検知器の精度 < 分類の精緻さ → 全体崩壊 |
| v449 | 連続 1D | 板情報 Depth ベースの Dynamic Position Sizing 構想 | **未実装** (構想のみ) | 流動性起因のサイジングは独自の切り口だが検証なし |
| **v451** | **連続→3値離散 (γ=0.80, PnL only)** | **拡張なし (シンプル化)** | **"Golden Era" — 最良結果** | **複雑な報酬/パラメータよりシンプルが勝つ** |
| v452 | 連続 1D + レジーム別 Kelly | DynamicPositionSizer (Kelly 基準 + レジーム乗数) | 損失回避には効果、利益生成には至らず | リスク管理層のサイジングとエージェント出力は別レイヤー |
| v454 | 連続→3値離散 + 確信度ペナルティ | Action 強度の校正試行 | **逆説的確信**: 確信が高いほど損失 (-38%) | 連続値の "大きさ" と収益性が**逆相関** |
| v456 | **2D 連続** (position + ttl) | TTL 次元を追加 | **推論側が 1D しか見ず 2D目は死蔵** | 訓練と推論で行動空間が不一致 = バグ源 |
| v459 | 2D 連続 (継承) | — | SAC ≈ Random (p=0.64), No-Go | 手数料が利益の 1,380% |
| v460 | **1D 連続 推奨** (015# §6.4) | 2D→1D に**縮約** | 設計段階 | maker-only では TTL は maker 側ロジックで管理 |

### 2.2 一貫したパターン

```
行動空間の拡張 → 常に失敗 or 無意味化
行動空間の縮約 → 改善をもたらした唯一の方向 (v451, v460 設計)

例外なし。
```

## 3. 別系統のサイジング設計（エージェント外部）

エージェントの行動空間とは別に、**リスク管理層**でのサイジング設計が複数存在する。

### 3.1 Kelly 基準ベース (v452, PHASE_3_2)

| 実装 | 内容 | 状態 |
|------|------|------|
| `kelly_position_sizer.py` | Half/Quarter Kelly + ボラティリティ調整 + ポートフォリオ最適配分 | PHASE_3_2 で実装済み |
| `DynamicPositionSizer` | Kelly 基準 + レジーム乗数 (BULL 1.5x, BEAR 0.5x, EXTREME_VOL 0.2x) | v452 で統合報告あり |

**教訓**: Kelly 基準は**勝率とペイオフ比が既知**の場合に有効。SAC の IC ≈ 0 (方向予測力なし) の状態では Kelly の入力が定義不能であり、算出結果は意味を持たない。

### 3.2 P&L 実績ベース (v460 方策 B)

| 実装 | 内容 | 状態 |
|------|------|------|
| `lot_sizer.py` | fill_rate / AS_ratio / 直近 PnL に基づく 0.001–0.005 BTC 段階調整 | 033# で実装・稼働中 |

**特性**: 予測力を前提とせず、約定実績のみに基づくフィードバック。現フェーズ (G1.1) に適合。

### 3.3 流動性ベース (v449 構想)

| 実装 | 内容 | 状態 |
|------|------|------|
| 構想のみ | 板の Depth に応じた Dynamic Position Sizing + 報酬へのスリッページペナルティ | **未実装** |

**評価**: v460 のマイクロストラクチャ特徴量（depth_imbalance, bid_depth_slope 等）と親和性が高い。ただしエージェントの action space ではなく、リスク管理層に組み込むのが妥当。

## 6. v454 「逆説的確信」の詳細（最重要教訓）

v454 で発見された **Inverse Confidence Paradox** は、行動空間拡張を議論するうえで最も重要な事実である。

| Action 絶対値 | 意味 | 実際の収益 |
|-------------|------|----------|
| 大きい (> 0.6) | モデルが「自信満々」 | **-38% の大損失** |
| 小さい (< 0.2) | モデルが「迷っている」 | **+12% の利益** |

**原因**: 連続値 → 3 値離散化の変換 (heavy_env/core.py) において、Action の大きさが環境側で "段差" になり、強い確信が校正されにくい。

**含意**: SAC の連続出力の「大きさ」に意味を持たせる拡張（lot sizing = 確信度のスケーリング等）は、確信度校正が不十分な状態では**損失を増幅する**。v444/v445 のレジーム別サイジングや v452 の Kelly 基準が利益生成に至らなかった遠因でもある。

## 9. 別 AI エージェントへのレビュー依頼事項

本文書を共有資料として使用する場合、以下の問いへの意見を求めることを推奨:

1. **行動空間は 1D のまま G2/G3 を進めるべきか、あるいは早期に 2D を試すべきか？**
   - 本文書の立場: 1D で Gate を順に通過してからエビデンスベースで判断
   - 反論の余地: 「早期に 2D を試して失敗すれば早く判断できる」という accelerated failure 戦略

2. **方策 A/B のルールベースを RL に置換する価値はあるか？**
   - 本文書の立場: G3 通過後に定量比較で判断
   - 反論の余地: 「RL による最適化は人間のルールを上回る可能性がある」

3. **v452 の Kelly 基準と v460 の P&L 実績ベース方策 B は統合すべきか？**
   - 本文書の立場: IC ≈ 0 では Kelly の入力が定義不能。方策 B のみが現段階で有効
   - 反論の余地: 「G1 通過後の IC > 0 環境では Kelly が最適解になり得る」

4. **v454 の逆説的確信は action space 設計の根本的欠陥か、それとも特徴量不足の副作用か？**
   - 本文書の立場: 確信度校正の問題は action space 拡張でさらに悪化する
   - 反論の余地: 「適切な特徴量があれば確信度は校正される」
