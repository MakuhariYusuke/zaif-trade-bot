## §0 渙三爻と之卦 — 巽為風

### §0.1 渙 (59) 三爻変 → 巽為風 (57)

渙卦の爻 (下から):
```
━━━  陽  六
━━━  陽  五
━ ━  陰  四   ← 巽(風)
━ ━  陰  **三** ← 変爻 (陰→陽)
━━━  陽  二
━ ━  陰  初   ← 坎(水)
```

三爻変後:
```
━━━  陽  六
━━━  陽  五
━ ━  陰  四   ← 巽(風)
━━━  **陽**  三
━━━  陽  二
━ ━  陰  初   ← 巽(風)
```

**之卦: 巽為風 (57) — 重巽**

### §0.2 解釈の多義性

爻辞「渙其躬、無悔」の読み方:

| 返り点 | 読み下し | 解釈 |
|--------|---------|------|
| 従来 (671#) | 其の**躬**(み)を渙(ちら)す | 自我・執着を散らす |
| 別訓 | 其の**躬**(からだ)を渙す | 構造・体制そのものを解体する |
| 逆読 | **渙**が其の**躬**を為す | 分散こそが本体を形作る |

「躬」=「からだ」と訓じた場合、散らすべきは心理的執着ではなく **物理構造** — すなわちシステムの Safety 層、ML パイプライン、min_spread ガードそのもの。

### §0.3 之卦・巽為風の示唆

巽為風の卦辞: 「巽。**小**亨。利有攸往。利見大人。」

- **小しく亨る** — 劇的変革ではなく、微小で持続的な浸透
- **重巽 = 風の上に風** — 一度の風は木を揺らすだけ。重なる風が地形を変える
- **利見大人** — 客観的に状況を見る者 (=データ) に従え

→ アーキテクチャの大規模リファクタではなく、パラメータの漸進的調整で検証サイクルを回す。

### §2.4 情報理論的解釈

- AS ステータス 1 bit が PnL 予測に 0.48 nats (= 0.70 bits) の情報を持つ

→ **SkipGate の予測精度を 10 倍にしても、AS のラベルを直接予測する単純なモデルに勝てない。**

## §3 Glosten-Milgrom モデル — Adverse Selection の構造

### §3.1 全体推定

| パラメータ | 値 | 意味 |
|-----------|---|------|
| α (informed rate) | 0.237 (23.7%) | 注文の 23.7% が情報トレーダー |
| E[loss \| informed] | -6.78 bps | 情報トレーダーに捕まると avg -6.78 bps |
| E[gain \| uninformed] | +1.81 bps | ノイズトレーダーから avg +1.81 bps |
| **Implied min half-spread** | **2.11 bps** | **Break-even に必要な最小片側スプレッド** |

Glosten-Milgrom の break-even 条件:
$$s^* = \frac{\alpha \cdot |\Delta V|}{1 - \alpha}$$

現在の quoted half-spread avg = 1.11 bps < implied min 2.11 bps → **理論上、現行スプレッドでは break-even できない**

### §3.2 スプレッド帯域別 α — Safety 層の逆説

| スプレッド帯 | α | E[loss] | E[gain] | Implied min HS | n |
|-------------|---|---------|---------|---------------|---|
| **0-1500 JPY** | **0.212** | -6.4 | +1.40 | **1.72** | 208 |
| **1500-2500 JPY** | **0.216** | -7.2 | **+2.11** | **1.99** | 449 |
| 2500-3500 JPY | **0.267** | -6.6 | +1.80 | 2.39 | 472 |
| 3500+ JPY | 0.244 | -6.8 | +1.52 | 2.21 | 168 |

**"narrow spread = 高 AS リスク" という前提は誤り。**

- ナロースプレッド (0-1500): α=21.2% — **最も低い** informed rate
- ワイドスプレッド (2500-3500): α=26.7% — **最も高い** informed rate

**min_spread_atr は α が低く break-even しやすい帯域を遮断し、α が高く break-even が困難な帯域のみを通過させている。**

## §4 Realized Spread 分解 — マイクロストラクチャの真実

### §4.1 全体

$$\text{Quoted HS} = \text{Realized HS} + \text{AS cost}$$

| 指標 | 値 (bps) |
|------|---------|
| Quoted half-spread avg | 1.11 |
| **Realized half-spread avg** | **+0.88** |
| AS cost avg | 0.23 (20.9%) |

**Realized spread は正。Maker は平均して per-fill で +0.88 bps を稼いでいる。**

（注: PnL30 の -0.231 bps と矛盾するように見えるが、realized spread はスプレッドからの収入のみを評価し、在庫リスクを除外するため誤差がある）

### §4.2 帯域別 — 衝撃の結果

| スプレッド帯 | Quoted HS | Realized HS | AS cost | AS/Quoted |
|-------------|-----------|-------------|---------|-----------|
| 0-1500 JPY | 0.51 | 0.25 | 0.25 | 50% |
| **1500-2500 JPY** | **0.92** | **1.01** | **-0.09** | **-10%** |

**1500-2500 帯域: AS cost が負。Realized > Quoted。マーカーが quoted 以上に稼いでいる。**

解釈: この帯域では「情報トレーダー」と分類された fill でも、30s 後の mid 移動が小さく、スプレッド収入が中間 price impact を上回る。

## §9 統合解釈 — 五つの理論が指し示すもの

### §9.1 理論横断サマリ

| 理論 | 発見 | 含意 |
|------|------|------|
| **統計学** | avg PnL30 の CI が 0 を含む | 「赤字構造」は統計的に有意でない |
| **情報理論** | 全 ML feature の MI ≤ 3% | ML 層が PnL に寄与する情報を持たない |
| **Glosten-Milgrom** | narrow α < wide α | min_spread_atr が低 α 帯域を遮断 |
| **Realized Spread** | 1500-2500 で AS cost < 0 | NFQ 遮断帯域が最も有利 |
| **Fill Prob Model** | offset と fill prob が独立 | Offset pipeline が fill 制御に無効 |

### §9.2 「データの嘘」の解剖

670#「avg PnL -0.54 bps = 構造的問題」は **3 つのバイアスの合成**:

1. **Simpson's Paradox**: AS/Non-AS の混合比率が結果を支配。Non-AS は黒字なのに、AS が 24% 混入するだけで全体が赤字に見える
2. **Selection Bias**: NFQ が低α帯域を遮断 → 残る fill は高α帯域に偏る → avg PnL が見かけ上悪化
3. **Statistical Insignificance**: そもそも avg PnL30 の CI が 0 を含み、「有意に負」とすら言えない

### §9.3 之卦・巽為風に従う戦略

巽 = 微小で持続的な浸透。大手術ではなく、検証可能な小さな変更を積み重ねる。

**Step 1 (微風)**: min_spread_atr_mult を現行値から 20% 引き下げ
- 効果: 1500-2500 帯域の一部がフィルタを通過
- 検証: fill rate / avg PnL30 / α の変化を 3 日間モニタ
- リスク: 低い (break-even implied HS = 1.99 bps で、この帯域は十分カバー)

**Step 2 (重風)**: Step 1 の結果を見て追加緩和
- min_spread を実効 1750-2000 JPY 付近に漸進的に調整

**Step 3 (「大人を見るに利し」)**: AS 予測モデルの作り直し
- 現 SkipGate の MI = 0.05 nats は使えない
- AS 予測に有効なフィーチャーを探索 (cross_venue_lead_lag_spread_bps が ρ=-0.041 & MI=0.064 で最大 — 微弱だが唯一の手がかり)

## §11 「データに嘘をつかせない」ための方法論的教訓

1. **常に CI を報告する**: 点推定値だけでは嘘が紛れ込む。671# の「avg30 = -0.54」は CI 付きなら「**-0.54 ± 0.6**」で、読む側が判断できた
2. **MI を使う**: 線形相関 r だけでは非線形依存を見逃す。ただし MI も万能ではない — 有限サンプルでの推定バイアスがある (MI の下限 ≈ 0.05 nats はバイアスの可能性)
3. **理論モデルを当てはめる**: Glosten-Milgrom は「α × loss = (1-α) × gain」という構造を強制し、ノイズに惑わされにくい
4. **分布間比較には KL を使う**: 平均値の比較は分布の形状を無視する。KL = 4.6 は「AS fill と Non-AS fill は別の世界」を定量的に示す
5. **Simpson's Paradox を常に疑う**: 集計データと条件付きデータで結論が反転する場合、条件付きを信じる。全体の avg PnL < 0 だが AS=False の avg PnL > 0
