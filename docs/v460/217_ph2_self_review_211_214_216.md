### Bug-2 SIGNIFICANT: MCB σ計算で偽 HALT

| 項目 | 内容 |
|---|---|
| ファイル | `scripts/v460/lib/micro_circuit_breaker.py` |
| 原因 | `std(abs(changes))` を使用 → 一定振幅 ±1% 反復時 `std([1,1,1,...]) ≈ 0` → 微小変動でも z-score 巨大 → 偽 HALT |
| 修正 | `std(raw_changes)` に変更。z-score は符号を含む分散で計算 |
| 重大度 | SIGNIFICANT — 安定相場で false alarm |

### Bug-3 SIGNIFICANT: MCB deque maxlen 不一致

| 項目 | 内容 |
|---|---|

| 修正 | 全 deque を maxlen=720 (= 24h ÷ 120s) に統一 |
| 重大度 | SIGNIFICANT — σ window が設計値の 1/3〜1/24 |
