## 2. 対立する主張の検証

### 2.1 ev_offset と base-rate fallacy

| 主張者 | 主張 |
|--------|------|
| 591# | tail loss の 100% が `decision_path=ev_offset`。ev_offset 経路が toxic fill を通しているのが問題 |
| 592# | filled の 99.6% が ev_offset なので、テール100%は母集団の偏り（base-rate fallacy）。ev_offset 自体が悪いのではない |

**実測**: filled 804 件中 **804 件 (100.0%)** が `decision_path=ev_offset`。592# の「99.6%」はやや過小だが、本質的主張は正しい。

**判定**: **592# の指摘は正当**。ev_offset 100% は当然の帰結であり、因果ではない。ただし、591# の洞察の本質は「ev_offset *パス自体*が悪い」ではなく「ev_offset パスの参加条件が甘い」という方向で、これは別途検証に値する。

### 2.2 [最重要] CV lead-lag 数値 — 591# vs 592#

| 主張者 | buy applied/total | sell applied/total |
|--------|-------------------|---------------------|
| 591# | 236/447 | 19/352 |
| 592# | 155 fills | 101 fills |
| **実測** | **236/450** | **21/354** |

**判定**:
- **591# はほぼ正確**（buy 236/447 → 実測 236/450、sell 19/352 → 実測 21/354。僅差のみ）
- **592# は幻覚**。「buy: 155, sell: 101」という数値はログのどこにも対応しない。592# は 591# を「数値捏造」と断罪しているが、**592# 自身の数値の方が捏造**

### 2.3 c164d21d の buy CV applied PnL

| 主張者 | 主張 |
|--------|------|
| 592# | c164d21d buy CV applied = **-3.21 bps**（「壊滅的」と断言） |
| **実測** | c164d21d buy CV applied = **+1.06 bps** (n=11) |

**判定**: **592# は完全に誤り**。実測は +1.06 であり、「壊滅的」どころか**プラス**。592# はこの誤ったデータに基づいて「Widen は機能しない」→「提案 C: CV Widen 廃止」を提唱しており、**提案の根拠自体が崩壊している**。

ただし、sell 側 CV applied は n=3 で PnL=-6.67 と非常に悪い（全 3 件が cap_hit=true）。CV の問題は buy ではなく**sell 側の cap_hit** にある。

### 2.4 macro_strong_down × c164d21d

| 主張者 | 主張 |
|--------|------|
| 592# | c164d21d では macro_strong_down 約定 = **0件**。590# P1 は幽霊との戦い |
| **実測** | c164d21d の macro_strong_down レコード = **0件**、filled = **0件** |

**判定**: **592# は正確**。現行 SHA では macro_strong_down が発生していないため、590# の P1 は確かに現行 SHA に対しては該当しない。ただし、市場環境が変われば再発する可能性はあり、完全に「無駄」とまでは言えない。

## 9. 教訓

1. **レビュー文書自体もファクトチェックが必須**。592# は 591# の「幻覚」を指摘しつつ、自身がより深刻な幻覚を含んでいた（CV 数値、c164d21d buy CV PnL）。
2. **base-rate fallacy は常に検査すべき**。「この条件の損失率が高い」→「この条件が原因」は成立しないことが多い。592# のこの指摘は金融工学的に正当。
3. **提案は根拠データを明示し、その正確性を検証してから採用する**。根拠データが誤っていれば提案全体が崩壊する（592# 提案 C）。
