## §2 Permutation Test (§7)

MC bootstrap (§5) とは根本的に異なるアプローチ:
- MC: Before/After の **異なる pool** からサンプリング → pool が異なれば有意になりやすい
- Permutation: **同一 pool** の中で Before/After **ラベルをシャッフル** → 帰無仮説を直接検定

### 結果
```
Before: n=161, mean=+0.322 bps
After:  n=131, mean=+0.917 bps
観測差: +0.595 bps

p-value (one-sided): 0.0953
帰無分布: mean=-0.003, std=0.458
帰無 95%CI: [-0.894, +0.902]
```

| 解釈 | 詳細 |
|---|---|
| p=0.0953 | α=0.05 未達、α=0.10 ボーダー |
| 非偶然の可能性 | 約 90.5% の確率で filter 効果は偶然ではない |
| **不十分な理由** | サンプル数 (n=131 vs 161) が統計的検出力のボトルネック |

**MC (p=0.000000) vs Permutation (p=0.0953)** の乖離は、MC が pool 効果を検定しているのに対し、Permutation が真のラベル効果を検定していることによる。Permutation の方が保守的で正確。

## §4 検出力分析 (§9)

| Cohen's d | 検出力 | 必要 n (各群) | 追加日数 |
|---|---|---|---|
| 0.05 (微小) | 23.4% | 4,949 | 23.8 d |
| 0.10 (小) | 54.1% | 1,238 | 5.5 d |
| **0.126 (現在)** | **68.5%** | — | — |
| 0.15 | 78.3% | 550 | 2.1 d |

**現在の効果サイズ d=0.126 で power=68.5%** — 検出力不足が Holm gate 不通過の主因。

### 重要な示唆
- **追加 0.9 日 (n≈310/群) で d=0.20 の効果を 93.4% の確率で検出可能**
- fill_test を再開すれば **約 1 日で Holm-Bonferroni 再検定が意味を持つ段階に到達**
- 現在の Permutation p=0.0953 も、データ増加で 0.05 を下回る公算が高い

## §5 統合判断と推奨アクション

### エビデンスの重み付け

| 手法 | 結果 | 信頼度 | 方向 |
|---|---|---|---|
| Holm-Bonferroni (§4) | 全戦略 ❌ | 高 (保守的) | 不確定 |
| Permutation Test (§7) | p=0.0953 ⚠️ | 高 (正確) | 改善示唆 |
| MC Bootstrap (§5) | After >> Before | 中 (pool 依存) | 改善 |
| 時系列安定性 (§8) | After 全指標改善 | 中-高 | 改善 |
| マルチメトリクス (§3) | 全指標改善 | 中 | 改善 |
| 検出力 (§9) | 68.5% (不十分) | 定量的 | データ不足 |

**5/6 の手法が改善方向を示すが、統計的有意水準に達するものがない。**
原因は明確: **サンプル数不足 (1.4 日, n=131/161)**。

### 推奨アクション (優先順)

1. **fill_test を即座に再開** — 追加 1 日で検出力が劇的に改善
2. 再開後 1 日経過時点で §4/§7/§9 を再実行
3. Permutation p < 0.05 かつ Holm 通過なら Go 判定
4. それでも通過しなければ filter 自体の再設計を検討
