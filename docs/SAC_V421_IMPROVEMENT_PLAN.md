# SAC v421 Balanced Trading - 改善計画ドキュメント

## 概要
SAC v420 Hold RelaxedのBUYバイアス問題を修正したv421モデルのさらなる改善計画。
目標：安定して儲かるスキャルピングトレードモデルを実現。

## 1. 特徴量強化

### 現在の状況
- **トレンド指標**: 60個の特徴量を選択済み
- **選定理由**: 価格トレンドの多角的把握（移動平均、Ichimoku、Supertrendなど）
- **特徴量数**: 約80個（価格・出来高・テクニカル指標）

### 改善提案
- **追加検討指標**:
  - モメンタム指標: Williams %R, Ultimate Oscillator
  - ボラティリティ指標: Chaikin Volatility, Normalized ATR
  - 市場構造指標: Order Flow, Market Profile
  - 時間帯指標: 月次/四半期サイクル、市場セッション
  - 外部データ: ニュースセンチメント、Googleトレンド、経済指標

- **特徴量削減**: 相関の高い指標を統合（例: 複数のRSIバリエーション）
- **動的特徴量**: 市場ボラティリティに応じた重み付け

## 2. データ品質向上

### 改善計画
- **データ拡張**: より長い期間の過去データ（1年以上）を追加
- **複数時間軸**: 1分/5分/15分/1時間の特徴量統合 ✅ **実装完了**
- **リアルタイム適応**: 市場変動へのオンライン学習データ生成
- **異常値処理**: 極端な価格変動のフィルタリングと補正
- **データバリデーション**: 欠損値・異常値の自動検知システム

### 複数時間軸実装状況
- **実装日**: 2025-10-17
- **実装内容**: 
  - RSI, ATR, ADX, EMA Cross, Heikin-Ashiの多時間軸対応

- **効果**: SACアルゴリズムの複数時間軸分析能力向上

## 3. 報酬関数最適化

### 現在の問題
- **長時間学習時の問題**: 報酬が1.000または-1.000に張り付く
- **原因**: 極端な報酬設計による勾配消失/爆発

### 改善計画
- **スキャルピング志向**: 短期取引（数分〜数十分）を奨励
- **報酬クリッピング緩和**: 過度な上下限を緩和
- **リスク調整リターン**: Sharpe ratioベースの報酬要素追加
- **取引頻度最適化**: 過度な取引/過少な取引のバランス
- **ダイナミック報酬**: 市場ボラティリティに応じた報酬スケーリング

### 具体的な修正
```json
{
  "reward_clip_min": -50.0,
  "reward_clip_max": 50.0,
  "short_term_bonus": 0.1,
  "scalping_penalty": -0.01
}
```

#### **適応型特徴量選択 (Adaptive Feature Selection)**
- **提案**: 市場状態に応じた動的特徴量重み付け
  - トレンド相場：トレンド指標（ADX, MACD, EMAクロス）を重視

#### **詳細実装計画**

##### **1. コンセプトドリフト検知 (Concept Drift Detection)**
- **統計的手法**:
  - Kolmogorov-Smirnov検定: 分布の変化を検知
  - CUSUM (Cumulative Sum) 検定: 平均値の変化を監視
  - Page-Hinkley検定: 逐次変化点検知
- **MLベース手法**:
  - ADWIN (Adaptive Windowing): 動的ウィンドウによる変化検知
  - DDM (Drift Detection Method): 誤分類率ベースの検知
  - EDDM (Early Drift Detection Method): 誤分類率分布の変化検知
- **時系列特化手法**:
  - Time Series Change Point Detection
  - Seasonal-Trend decomposition
  - Fourier変換ベースの周期性変化検知
- **実装アプローチ**: River/MLflow統合によるリアルタイム検知パイプライン

##### **2. 自動再学習トリガー (Automatic Retraining Triggers)**
- **パフォーマンス低下検知**:
  - 予測精度の閾値監視（例: 精度90%以下でトリガー）
  - 損失関数のトレンド分析
  - 取引成功率の継続的監視
- **データ分布変化検知**:

# ⚡ 計算時間短縮のための改善策

## 概要
2025-10-17実施の処理時間分析により、SAC v421の計算効率化に向けた具体的な改善策を整理。トレーニング時間短縮と推論速度向上を目的とした包括的な最適化戦略を提案。

## 1. データ処理の最適化

### 特徴量計算の効率化
- **問題点**: 156個の多時間軸特徴量計算に時間がかかる
- **改善策**:
  - インクリメンタル特徴量計算（差分更新のみ）
  - 特徴量計算の並列化（マルチプロセス/マルチスレッド）
  - 計算結果のキャッシュ化（Redis/Memory cache）
  - 不要特徴量の動的スキップ
- **期待効果**: 特徴量計算時間を50-70%削減

### データローディングの改善
- **問題点**: 大規模時系列データのI/Oボトルネック
- **改善策**:
  - メモリマップドファイルの活用
  - データプリフェッチングの実装
  - 非同期データローディング
  - データ圧縮（gzip/lz4）の検討
- **期待効果**: データ読み込み時間を30-50%削減

### キャッシュ戦略の強化
- **改善策**:
  - 計算済み特徴量の永続化キャッシュ
  - モデル推論結果のキャッシュ
  - 中間計算結果のメモリプール管理
- **期待効果**: 繰り返し計算の完全排除

## 2. モデルアーキテクチャの最適化

### モデル圧縮の実装
- **量子化 (Quantization)**:
  - 動的量子化（FP32→FP16/INT8）
  - 混合精度トレーニングの導入
  - 推論時の動的量子化適用
- **プルーニング (Pruning)**:
  - 構造的プルーニング（チャネル/フィルタ単位）
  - 動的プルーニング（重要度ベース）
  - スパース性活用による高速化
- **知識蒸留 (Knowledge Distillation)**:
  - 教師モデル（大規模）→生徒モデル（軽量）
  - 蒸留損失の設計と最適化
  - 多段階蒸留の実装

### ネットワーク設計の効率化
- **改善策**:
  - 深度分離畳み込みの活用
  - アテンションの効率的実装（Linformer/Performer）
  - 動的ネットワーク（入力に応じた計算量調整）
  - 条件付き計算（重要部分のみ計算）
- **期待効果**: モデルサイズ50-80%削減、推論速度2-5倍向上

## 3. トレーニングプロセスの最適化

### 混合精度トレーニング (Mixed Precision Training)
- **実装内容**:
  - FP16/FP32混合によるメモリ効率化
  - 勾配スケーリングによる数値安定性確保
  - Apex/NVIDIA AMPの活用
- **期待効果**: トレーニング速度1.5-2倍向上、メモリ使用量削減

### 勾配累積 (Gradient Accumulation)
- **改善策**:
  - バッチサイズ拡張による学習安定性向上
  - メモリ制約下での大バッチ学習
  - 動的バッチサイズ調整
- **期待効果**: GPUメモリ効率化、学習品質向上

### オプティマイザーの最適化
- **改善策**:
  - AdamWからより効率的なオプティマイザーへ移行
  - 学習率スケジューラーの改善（OneCycleLR/CosineAnnealing）
  - 二次モーメントの効率的計算
- **期待効果**: 収束速度向上、安定性改善

### 早期停止とチェックポイントの改善
- **改善策**:
  - より賢い早期停止基準（複数指標監視）
  - チェックポイントの効率的保存（差分保存）
  - 学習再開の最適化
- **期待効果**: 無駄なトレーニング時間の削減
