# SAC 5000ステップトレーニング問題分析と対策

## 概要
5000ステップのSACトレーニングを通じて、以下の問題が発見されました：
- 極端な探索不足（アクション分散 < 0.02）
- BUY/SELLアクションの完全な欠如
- 過度な保守性（HOLDシグナル > 98%）

## 発見された問題

### 1. 探索不足（Exploration Deficiency）
**現象**: アクションの標準偏差が非常に小さく（< 0.02）、全てのアクションが-0.02〜0.02の狭い範囲に集中
**影響**: エージェントが十分な探索を行わず、最適解を見つけられない

### 2. BUY/SELLアクション欠如（Action Signal Absence）
**現象**: BUYシグナルとSELLシグナルの両方が0
**影響**: トレードが全く実行されず、ポートフォリオが変化しない

### 3. 過度な保守性（Excessive Conservatism）
**現象**: HOLDシグナルが99%以上を占める
**影響**: エージェントがリスクを避けすぎて、学習機会を失う

## 試行された対策

### 対策1: 基本的な探索パラメータ調整
- エントロピー係数: 0.1 → 0.5
- 学習開始ステップ: 100 → 50
- 結果: アクション分散 0.0092 → 0.0198（改善したが不十分）

### 対策2: 積極的な探索促進
- アクション閾値: ±0.1 → ±0.05
- 非アクション罰則: -0.0001 → -0.001
- アクション報酬: +0.0005（新規追加）
- エントロピー係数: 0.5 → 1.0
- 学習率: 3e-4 → 5e-4
- 学習開始: 50 → 25
- 結果: アクション分散 0.0198 → 0.0055（悪化）

### 対策3: 極端な探索強制
- アクション閾値: ±0.05 → ±0.02
- 非アクション罰則: -0.001（維持）
- アクション報酬: +0.0005（維持）
- エントロピー係数: 1.0（維持）
- 結果: 依然としてアクション分散 < 0.02、問題解決せず

## 根本原因の分析

### 1. 報酬関数の設計問題
現在の報酬関数はポートフォリオ価値の相対変化に基づいているが：
- 短期的なノイズに敏感すぎる
- 長期的なトレンドを十分に反映していない
- アクションの実行自体を十分に奨励していない

### 2. 環境の複雑さ vs トレーニング期間の不整合
- 環境が複雑すぎて、5000ステップでは学習が不十分
- SACアルゴリズムの特性上、より長いトレーニング期間が必要

### 3. 観測空間の設計問題
現在の観測空間（価格、トレンド、ポジション、残高比率、時間進行）が不十分：
- 市場のボラティリティ情報を欠如
- リスク指標が含まれていない

## 推奨される対策

### 短期対策（次フェーズ）
1. **トレーニング期間の延長**
   - 5000ステップ → 50000ステップ以上
   - 段階的な学習（curriculum learning）の導入

2. **報酬関数の改良**
   - Sharpe ratioベースの報酬関数
   - ドローダウン罰則の追加
   - 取引コストの考慮

3. **観測空間の拡張**
   - ボラティリティ指標の追加
   - テクニカル指標の追加（RSI, MACDなど）
   - 市場センチメント指標

### 長期対策（アーキテクチャレベル）
1. **アルゴリズムの変更**
   - PPOやA2Cなど、より安定したアルゴリズムの検討
   - Ensemble学習の導入

2. **環境設計の見直し**
   - より現実的な市場シミュレーション
   - 複数資産ポートフォリオの導入

3. **ハイパーパラメータ最適化**
   - 自動ハイパーパラメータチューニング（Optunaなど）
   - メタ学習の検討

## 結論
5000ステップのトレーニングでは、SACアルゴリズムが十分に探索を行えず、保守的な行動パターンに陥ることが判明しました。根本的な解決には、トレーニング期間の延長と報酬関数の改良が必要です。

次回のイテレーションでは、以上の対策を適用し、より効果的な学習環境の構築を目指します。
