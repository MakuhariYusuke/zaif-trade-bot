# v455 感度分析結果の考察と本格学習方針

## 結果サマリ
- **Best Setting**: `min_edge_mult=1.5`, `vol_floor=0.002`
- **平均報酬**: **-109**（他候補は -1000 〜 -2800）
- **特徴**: 低ボラ局面の無駄な往復を抑制し、損失速度が最も緩やか。
- **生存時間**: 平均430ステップ（約7時間）

## 考察（複数視点）
### 1) HFT / マイクロストラクチャ視点
- **低ボラ＝コスト優位の局面**が支配的で、スプレッド負けの構造が明確。
- `vol_floor` を 0.2% に上げると、**取引頻度が落ちる代わりに損失が激減**。
- 結果として「取引しないこと自体が最適行動に近い」局面が多い。

### 2) ML / 強化学習視点
- `min_edge_mult=1.5` が最良という事実は、**環境内の報酬がコスト優位に傾いている**ことを示唆。
- 収益の改善は「当てる能力」よりも **取引回避の学習**に強く依存。
- `edge_shortfall` と `trade_cost` の推移を学習曲線として監視するのが必須。

### 3) リスク管理視点
- 生存時間が短縮しても、**損失速度が緩くなるのは重要な前進**。
- 現状は「損失最小化フェーズ」。まずは **破産確率をほぼゼロにする**ことが妥当。

## 結論
- **最適設定は `min_edge_mult=1.5`, `vol_floor=0.002` で確定**。
- 次は「本格学習」に移行し、**損失最小化 → 損益分岐点への移行**を狙う。

## 本格学習の推奨ステップ数
### 統計的な目安
```
n >= (z * sigma / epsilon)^2
steps_needed = n / trade_rate
```

### 実務的推奨
- **300k – 600k steps** を推奨（trade_rate が低い前提）。
- 100万 steps は **trade_rate が極端に低い場合のみ**必要。

## 学習評価の観測指標
- `hft/edge_shortfall_val` が低下しているか
- `hft/trade_cost_val` が低下しているか
- `hft/vol_ratio_val` 分布が適切か
- Net PnL / trade_count の改善
