# Phase 6: High Frequency Trading (HFT) Fine-tuning

## 概要
Phase 5 で学習したモデルは、高い収益性と安定性（Sortino Ratio 2.38）を示しましたが、取引回数が極端に少なく（Buy & Hold戦略）、1分足での高頻度取引という当初の目的を達成できていませんでした。
これは、取引手数料（0.1%）が1分間の期待値動きよりも大きいため、AIが「取引しないことが最適解」と学習してしまったためです。

Phase 6 では、この「不作為の局所解」から脱却し、アクティブな売買を行わせるためのファインチューニングを行います。

## 戦略と変更点

### 1. 取引コストの撤廃 (Simulation)
- **変更:** `transaction_cost`: `0.001` (0.1%) -> `0.0000` (0.0%)
- **目的:** Maker手数料（マイナス手数料やゼロ手数料）を想定し、スプレッドや手数料を気にせず、純粋な価格変動を捉える能力を学習させます。

### 2. 短期報酬の重視
- **変更:** `gamma` (割引率): `0.99` -> `0.95`
- **目的:** 将来の不確実な大きな利益よりも、直近の確実な利益を優先させ、短期売買を促進します。

### 3. 探索の強制 (Entropy Regularization)
- **変更:** `ent_coef`: `auto` -> `0.05` (固定・高め)
- **目的:** 確率的な行動選択を強制し、現在の「Hold一択」というポリシーを崩して、Buy/Sellの行動を試行させます。

### 4. ドローダウンペナルティの厳格化
- **変更:** `drawdown_penalty_threshold`: `0.2` -> `0.05`
- **目的:** 短期売買において、含み損を抱えることを許容せず、早めの損切り（または建値決済）を学習させます。

## 実行計画
- **ベースモデル:** `models/sac_v450_phase5_stage4_pnl_focused.zip`
- **学習ステップ数:** 30,000 steps (短期集中)
- **出力モデル:** `models/sac_v450_phase6_hft.zip`

## 期待される成果
- 取引回数の大幅な増加
- 小さな利幅の積み上げによる収益カーブの形成
- （注: 手数料0での学習のため、実運用時の手数料負けリスクは別途バックテストで検証が必要）
